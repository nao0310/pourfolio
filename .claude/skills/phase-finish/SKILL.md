今のステップを仕上げます。

1. `npm test` を実行し、失敗があれば直す
2. `npm run serve` でBrowserペインに開き、このステップの画面と操作を確かめて、結果を短く報告する
3. `docs/ROADMAP.md` の該当ステップにチェックを付ける
4. `docs/PROGRESS.md` の先頭に、日付・ステップ番号・やったこと・確認結果・未解決・次の一手を追記する
5. 決めたことがあれば `docs/DECISIONS.md` に追記する
6. `/manual-update` と同じ手順で `docs/manual/` を更新する
7. 変更をコミットし、ブランチをpushして、PRを作る（タイトル例：[1-2] 豆の登録と在庫。本文に変更点・確認方法・未解決を書く）
8. 最後に、ユーザーがやることを番号付きで示す
   - PRの差分を見てマージする方法
   - 数分後にiPhoneのホーム画面のアプリを開き直して確かめる点
   - 撮ってほしい画面写真（手順書用）とファイル名
