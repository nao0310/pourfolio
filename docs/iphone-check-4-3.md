# iPhone確認：タイマーを使わずに記録して評価する（Ver 4.3）

ホーム画面のアプリで、上から順に確かめてください。できたら「A〜Eできた」、できなかったら記号と様子を教えてください。

- A：アプリを開き直して、画面の下に新しい版（Ver 4.3）の知らせが出る。「その他」のいちばん下が「Ver 4.3」
- B：下の「淹れる」を押すと、レシピのカードに「タイマーなしで記録」のボタンがある。押すと「実績の確認」の画面になり、上に「（レシピの名前）・タイマーなし」と出る
- C：「使った器具」に、レシピの器具（グラインダー・ドリッパー・フィルター・ケトル）が選ばれている。ドリッパーなどを別の器具に選び直せる
- D：「総時間」を入れて「保存する」を押すと「味の評価」の画面に変わり、評価を保存できる。そのあと「淹れる」→「前回と同じで淹れる」を押すと、計画の器具に選び直したドリッパーが出る
- E：もう一度「タイマーなしで記録」を押してから「記録せずにやめる」→「やめる」を押すと、レシピの計画の画面に戻る（実績の確認がまた開かない）。計画の画面の下に「タイマーを使わないとき」の枠のボタンがある
