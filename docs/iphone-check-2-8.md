# iPhoneでの確認表（ステップ2-8 総点検）

総点検で直した所を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。番号の後ろのかっこは `docs/debug/findings.md` の番号です。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 2.8）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 2.8 になりました」と、変わったことが3つ出る。「閉じる」を押すと消える

## B. 画面の移り方（3番）
1. 下のタブを「ホーム → 抽出 → 豆と在庫 → 分析 → その他」の順に押す
2. 画面がふわっと切り替わり、下のタブは動かずにそのまま残る（一瞬消えたり、白く光ったりしない）
3. iPhoneを「ダーク」にして（コントロールセンターで画面の明るさを長押し →「ダークモード」）、もう一度1を押す。画面を移るときに白く光らない
4. 「設定」→「アクセシビリティ」→「動作」→「視差効果を減らす」がオンなら、ふわっとせずにすぐ切り替わる（これで正しい）
- iOS 18.2 より前のiPhoneでは、ふわっとしないのが正しい動き。2の「タブが一瞬消えない」だけ確かめる

## C. お知らせを閉じる（1・2番）
1. 1杯淹れて評価を保存し、15分ほどたってからトップを開くと「冷めた味を評価しませんか」が出る
2. 「今回はしない」を押すと消え、「お知らせを閉じました。この杯ではもう出しません」と出る。トップを開き直しても出ない
3. ほかのお知らせ（「記録を書き出しましょう」など）の右上の「×」を押すと消え、いつまた出るかが出る
4. 冷めた味のお知らせは、落ち切ってから1時間たつと出なくなる

## D. 抽出のタイマー（5・16・17番）
1. 「スタート」を素早く2回押す。蒸らしが0:00で完了にならず、タイマーが進む
2. 最後の投で「注ぎ終えた」を素早く2回押す。落ち切り待ちになり、すぐには終わらない（もう一度押すと終わる）
3. タイマーの途中で画面が消えない（画面を消さない設定）。「やめる」→「はい」のあと、しばらく置くと画面がいつもどおり暗くなる

## E. 保存の2度押し（4・13番）
1. 実績の確認で「保存する」を素早く2回押す。評価の画面に移り、「直近の抽出」に同じ杯が2つ並ばない
2. 豆の画面の「1杯淹れた」を素早く2回押す。在庫の履歴に1件だけ増える

## F. 豆の画面（20番）
1. 入荷待ちの豆を開くと、画面の下に茶色の「届いた」が出る。重さが空のまま押すと、重さの欄に移る
2. 手元の豆を開くと、画面の下に「この豆で淹れる」が出る。押すと抽出の画面が開く
3. 「編集」は画面のいちばん下（「飲み切りにする」「削除」の並び）にある

## G. 評価（21・22・23番）
1. 評価の画面で「詳しく評価する」を開く。「好み」の1〜9が2段に並び、左手の親指だけで押し間違えずに押せる
2. 「強さ」は、まだ答えていないあいだ、つまみが出ない。線を押すとつまみが出る
3. 挽き目を記録していない杯を「酸っぱい」で評価すると、「提案を入れて淹れる（目盛りは手で）」と「湯温を2℃上げて淹れる（92℃ → 94℃）」が出る
4. トップの「直近の抽出」に「評価まで 2分10秒」のように出る

## H. Browserペインでは確かめられないもの（総点検の i1〜i9）
1. QRをカメラで読む（2-7 と同じ。「QRを読む」→「カメラで読む」）
2. レシピカードや月次レポートを印刷するとき、プレビューに「新しい版があります」が出ない
3. 写真を10枚ほど入れた記録を「書き出す」と、共有シートが出て保存できる
4. 機内モードでもアプリが開ける
5. 抽出の途中でアプリを閉じて開き直すと続きに戻れ、合図の音が鳴る（鳴らなければ教えてください）
6. 朝に開いたままにして夜に戻ったとき、「今日の1杯」やカフェインの表示が古いままにならない（古いままなら教えてください）
