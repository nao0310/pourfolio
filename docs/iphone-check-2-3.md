# iPhoneでの確認表（ステップ2-3）

冷凍ストック、コスト、店の台帳、送料無料のまとめ買いを、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 2.3）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 2.3 になりました」と、変わったことが3つ出る。「閉じる」を押すと消える
3. トップ画面のいちばん下に「Ver 2.3」が出ている

## B. 冷凍する（完了の確認）
1. 「豆と在庫」で、残りが多めの豆を押す。「残り」の重さを覚えておく
2. 「冷凍ストック」の「小分けにして冷凍する」を押す
3. 「1袋の量」が15g（1杯分）になっている。「袋の数」の「−」「＋」が片手で押せる
4. 袋の数を2にして「冷凍する」を押すと、「2袋（30g）を冷凍しました。袋に #1・#2 と書いておきましょう」と出る
5. 「冷凍ストック」に #1・#2 が並び、「残り」の重さは1.と同じで、その下に「常温 ○g＋冷凍 2袋（30g）」と出る
6. 「#1」の「取り出す」を押すと「#1（15g）を取り出し、常温に戻しました」と出て、冷凍の袋が1つになる。「残り」の重さは変わらない

## C. 冷凍した袋で淹れる
1. Bの豆で「淹れる」から抽出し、「実績の確認」まで進む（「タイマーを使わずに記録する」でもよい）
2. 「豆」の下に「冷凍の袋を使う：#2　15g・…」が出る。印を付けて「保存する」を押す
3. 評価の画面の上に「○○の残り ○g（あと○杯）」と出て、冷凍の袋が残っていれば「常温 ○g＋冷凍 ○袋」も出る
4. 豆の画面で、冷凍の袋が減り、「在庫の履歴」に「冷凍から取り出し +15g」と「抽出」が並ぶ

## D. 間違えたときの取り消し
1. 豆の画面の「在庫の履歴」で、Bで作った「冷凍」の「取り消す」を押す
2. 取り出した袋があるので「取り出した袋があるため、この冷凍は取り消せません」と出る（記録は変わらない）
3. 試した分を元に戻したいときは、「量り直す」で今の重さに合わせる

## E. コスト
1. 「豆と在庫」→ 上の「コスト」を押す
2. 「この1か月」に1杯の平均と今月の額が出る（価格を入れた豆で淹れていれば）
3. 「月の支出」に今月から6か月分が並び、横にはみ出さない
4. 「銘柄」「焙煎度」「購入先」を押すと表が切り替わる。表の文字が読める大きさになっている
5. 価格の入った豆の画面の「豆の情報」に「1gあたり」と「1杯の原価」が出る

## F. 店の台帳
1. 「豆と在庫」→ 上の「店の台帳」を押す
2. 「珈琲問屋」などの店ごとに、買った袋・回数・使った金額・平均★が出る
3. 店名の右の「☆」を押すと★に変わり、「○○をお気に入りにしました」と出る。もう一度押すと外れる

## G. 送料無料のまとめ買い
1. 「豆と在庫」→「買い物リスト」→「送料無料のまとめ買い」の「送料の設定」を押す
2. 珈琲問屋の案内を見て「送料」「送料無料ライン」を、冷凍庫に入る1杯分の袋の数を「冷凍庫に入る袋の数」に入れて「保存」を押す
3. 「次に買う候補」で1つ印を付けると、「合計 ○円。送料無料まで、あと○円」と出る
4. 価格の入った候補が2つ以上あれば、ラインに届く豆が「足す」ボタン付きで出る。「足す」を押すと注文メモに加わる

## H. 機内モード
1. 機内モードにして、アプリを閉じて開き直し、「コスト」と「店の台帳」が開ける
2. 機内モードを戻す
