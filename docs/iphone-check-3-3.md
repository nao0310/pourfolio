# iPhoneでの確認表（ステップ3-3 天気と生活、Ver 3.3）

3-3で作った「天気の地点」「暑い日のアイス」「生活との関係」を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。通信できる場所で始める。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.3）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 3.3 になりました」と、変わったことが3つ出る
3. 前からの豆・抽出・実験の記録が、そのまま残っている

## B. 天気の地点（本物の天気が取れるか）
1. 画面の下のタブ「その他」に「天気の地点」がある。押すと「天気の地点」の画面が開く
2. 「都道府県」で住んでいる都道府県を選び、「保存する」を押すと「地点を『○○』にしました」と出る
3. 「いまの様子」に、いまの天気（「○℃・湿度○%・晴れ」など）と今日の最高気温が出る。天気予報アプリの値と大きくずれていない
4. 「天気の付いた杯」が「○杯／○杯」と出て、この92日以内に淹れた杯に天気が付いている
5. 「暑い日の線」の「−」「＋」が押しやすく、「線を保存する」で「最高気温○℃以上の日にアイスをすすめます」と出る
6. いちばん下の「Weather data by Open-Meteo.com」を押すと、Open-Meteo のページが開く

## C. 通信がない日に淹れた杯
1. 機内モードにする
2. いつもどおり1杯淹れて保存し、評価する（保存が遅れたり、エラーが出たりしない）
3. 機内モードを切り、1時間ほどたってからトップ画面を開き直す
4. 「その他」→「天気の地点」の「天気の付いた杯」が1杯増えている（淹れた杯にあとから天気が付いた）

## D. 暑い日のアイス
（今の季節は暑い日がないので、線で試す）
1. 「天気の地点」で暑い日の線を、今日の最高気温より低くして（例：20℃）「線を保存する」を押す
2. トップ画面を開くと、「今日は暑い日です（最高○℃）」のカードが出る
3. 「急冷アイスで淹れる」を押すと抽出の画面が開き、アイス（氷の量の入った計画）になっている
4. 戻ってカードの右上の「×」を押すと閉じ、「今日はもう出しません」と出る。開き直しても今日は出ない
5. 線を28℃に戻して「線を保存する」を押す

## E. 生活との関係
1. 「分析」の「見る」に「生活との関係」がある（★のある杯が30杯未満なら「あと○杯で表示します」）
2. 30杯に届いていなければ、分析のいちばん下の「デモで見る」→「生活との関係」で見る
3. 「時間帯」「曜日」「気分」「気温」「天気」「季節」などの横の棒と数字が、ライト・ダークどちらでも読め、文字が切れたり横にはみ出したりしない
4. いちばん下の「季節ごとの好み」が4行（春・夏・秋・冬）で読める
