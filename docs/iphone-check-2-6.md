# iPhoneでの確認表（ステップ2-6）

今日の一杯・気分・量とアイス・新しい豆の最初のレシピ・AI相談を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 2.6）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 2.6 になりました」と、変わったことが3つ出る。「閉じる」を押すと消える

## B. 今日の一杯（完了の確認）
1. トップ画面の「今日の1杯」に「おすすめ：（豆の名前）」と、理由が2〜3行出る
2. 朝（5〜10時）なら「今の時間なので気分「目覚め」で選びました」と出る（ほかの時間は出ないこともある）
3. 「おすすめで淹れる」を押すと、抽出の画面に変わり、上に「★がいちばん高かった杯：…」か「…の最初のレシピ」と出る。左上の「‹ 淹れる」で戻る
4. 「ほかの候補・気分を変える」を押すと「今日の一杯」の画面に変わり、1〜3位の豆が理由と一緒に出る
5. 「気分」の「食後」を押すと、ボタンに色が付き、下に「狙い：ボディ重視…」と出る。順位や理由が変わることがある
6. 文字が小さすぎる・ボタンが押しにくいところがあれば教えてください

## C. カフェインを控える時刻
1. 「今日の一杯」の画面のいちばん下の「この時刻からカフェインを控える」を押し、今より前の時刻（例：今が20時なら 15:00）を選ぶ
2. 「15:00から控えるようにしました」と出て、上の候補の「淹れ方」に「少なめ」が付く
3. 豆の編集画面で「カフェインレス（デカフェ）」を押して保存した豆があれば、その豆が1位に来る（なければ飛ばしてよい）
4. 「使わない」を押すと元に戻る

## D. 量・アイス・気分
1. 「抽出」のタブからいつものレシピの「淹れる」を押す
2. 「量と気分」の「2杯」を押すと、「計画」の粉量と湯量が2倍になり、「注湯の予定」の最後の累計も湯量と同じになる
3. 「アイス（急冷）」を押すと、「計画」に「お湯」と「氷」が分かれて出る（お湯＋氷＝元の湯量）。下に「サーバーに氷 ○g を入れておきます」と出る
4. 「1杯」と「アイス」を元に戻すと、元の数字に戻る
5. 片手で、親指でボタンが押せる。文字が切れていない
6. （アイスで1杯淹れたときだけ）次に「前回と同じで淹れる」を押すと、「アイス（急冷）」に最初から印が付いている

## E. 新しい豆の最初のレシピ
1. 次に豆を登録したとき（テスト用に登録して、あとで削除してもよい）、豆の画面のいちばん上に「この豆の最初のレシピ」が出る
2. 右上に「似た豆から」「自分の初期値」「焙煎度の叩き台」のどれかが出て、太字の数字と理由が並ぶ
3. 「この計画で淹れる」を押すと、抽出の画面に変わり、「この豆の最初のレシピ」の枠に同じ理由が出る

## F. AIに相談
1. タブ「その他」→「AIに相談」を押す
2. 「次の1杯で何を変える？」に印が付いている。「文章をコピーする」を押す
3. 「コピーしました（○文字）」と出る（「コピーできませんでした」と出たら、その番号を教えてください）
4. メモアプリかチャットAIのアプリの入力欄を長押しして「ペースト」を押すと、「## 直近の抽出」の表などが入っている
5. （チャットAIを使うときだけ）答えの「【提案レシピ】」の部分をコピーし、「AIの答え」に貼って「読み取る」を押すと、粉量・湯量・湯温・挽き目が並ぶ。「この計画で淹れる」で抽出の画面に変わり、上に「AIの提案：…」と出る
