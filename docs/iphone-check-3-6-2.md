# iPhoneでの確認表（下のタブの作り直し、Ver 3.6.2）

下のタブがスクロールと一緒に上へ流れる不具合を、画面の作りから直しました（D-184）。前回（Ver 3.1.1）は、iPhoneで直ったかを確かめないまま進めてしまったので、今回は必ず確かめて、結果を教えてください。この作業環境には Safari のエンジン（WebKit）がないため、ここに書いたことは Chrome（Chromium）でしか確かめていません。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面に「新しい版（Ver 3.6.2）があります」が出たら「更新する」を押す（出なければ、アプリを閉じて開き直す）
2. ホームの「今日の1杯」の下に「Ver 3.6.2 になりました」が出る。読んだら「閉じる」を押す

## B. 下のタブ（いちばん大事）
1. ホームを開き、画面をいちばん下までスクロールする。5つのタブ（ホーム・淹れる・豆と在庫・分析・その他）が画面のいちばん下に付いたまま動かない
2. 同じことを「豆と在庫」「分析」「その他」「淹れる」でもする
3. 画面の途中で、上下にすばやく何度かスクロールする（いちばん上・いちばん下で引っぱってはね返す動きも）。タブは動かない
4. 下のタブを使って10回ほど画面を移る（ホーム → 豆と在庫 → 豆を1つ開く → 戻る → 分析 → その他 …）。どの画面でも1と同じ
5. 1日ほど、ふだんどおり使う。タブが上へ流れることがない

## C. 文字を入れたあと（キーボード）
1. 「豆と在庫」→ 豆を1つ開く →「編集する」を押し、「メモ」に何か入れる
2. キーボードの上の「完了」を押すか、画面の空いている所を押してキーボードを閉じる
3. 画面をいちばん下までスクロールする。下の「保存する」のボタンが画面の下に見えていて、タブの部分にすき間がない
4. 保存しないで戻る（左上の豆の名前を押す）。豆の画面でもタブがいちばん下のまま
5. 「その他」→「今日の1杯」の「カフェインを控える時刻」を選んで閉じたあとも、タブがいちばん下のまま

## D. 下に付くボタン
1. 豆を1つ開く。画面の下、タブのすぐ上に「この豆で淹れる」（入荷待ちなら「届いた」）が付いている。画面をスクロールしても、タブの上に付いたまま
2. 「淹れる」でレシピを選ぶ。画面の下に「スタート」が付いている
3. 淹れて「保存する」、評価して「保存する」までいつもどおり進める

## E. 「戻る」と位置
1. 「豆と在庫」の一覧を下のほうまでスクロールし、豆を1つ開く
2. 画面の左の端から右へなぞって戻る。一覧が、さっき見ていた位置のあたりで出る

## F. 前と変わったこと（決まりどおり）
1. iPhone の画面のいちばん上（時計のあたり）を押しても、いちばん上には戻らない。画面を下へなぞって戻る（D-184）
2. 印刷（レシピカード・月次レポート）は今までどおり印刷できる（使うときだけで大丈夫です）

終わったら、うまくいかなかった番号を教えてください（全部できたら「全部できました」）。B の5は、1日使ってからで大丈夫です。
