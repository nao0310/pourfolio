# iPhoneでの確認表（ステップ3-1 実験、Ver 3.1）

3-1で作った「実験」（条件の飲み比べ・トライアングルテスト・最適化）を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。前の表 `docs/iphone-check-2-8-2.md` がまだなら、先にそちらを済ませてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。量の少ないレシピ（粉10g前後）があると楽です。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.1）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 3.1 になりました」と、変わったことが3つ出る

## B. 実験の画面
1. 「豆と在庫」の上の小さなリンクの並びに「実験」がある。押すと「実験」の画面が開く
2. 「次に試す実験」に、直近に淹れた豆で「挽き目 24 → 22（2目盛り細かく）」のような案と理由が出る
3. 「新しく始める」の「豆」「条件」「トライアングル」のボタンが1行に収まり、片手の親指で押せる
4. 横にはみ出したり、文字が切れたりしている所がない（縦・横向き）

## C. 条件の飲み比べ
1. 「次に試す実験」の「この飲み比べを始める」を押すと、「条件」の欄に豆・レシピ・変える条件・幅が入った状態で開く
2. 「飲み比べを始める」を押し、「挽き目 22」の「淹れる」を押すと、抽出の画面の上に「このカップ：挽き目 22」と出て、「計画」の挽き目が22になっている
3. 2杯とも淹れると実験の画面に戻り、「カップ 1」「カップ 2」で★を付け、底を見て答え合わせができる
4. 結果に「挽き目を2目盛り細かく：★1つ良くなった（★3 → ★4）」のように出る

## D. トライアングルテスト
1. 「トライアングル」→「2つの豆」で2袋を選んで始め、AとBを淹れられる
2. 「2. 当てる」「3. 答え合わせ」のカップ1〜3のボタンが、片手で押し分けられる大きさ
3. 答え合わせのあと「当たり！」か「はずれ」と成績が出て、「同じ組でもう1回」で次が始まる

## E. 最適化
1. 豆の画面の「実験」の「最適化する」を押すと、「最適化を始める」の画面で、その豆と範囲の数字が入っている
2. 「最適化を始める」を押すと、待たされずに（2秒以内に）「次の1杯」が出る
3. 「この条件で淹れる」を押すと、抽出の画面の計画がその挽き目と湯量になっている
4. 「予想の地図」の表を指で横に動かせ、マスの文字がライト・ダークどちらでも読める
