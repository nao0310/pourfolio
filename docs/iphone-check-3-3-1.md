# iPhoneでの確認表（Ver 3.3.1 天気を受け取れない不具合の直し）

`docs/iphone-check-3-3.md` で「天気を受け取れませんでした」となったところを、もう一度確かめるための表です。うまくいかなかった番号と、出た文（かっこの中も）を教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。通信できる場所で始める。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.3.1）があります」が出たら「更新する」を押す
2. トップ画面に「Ver 3.3.1 になりました」と出る

## B. 天気を受け取る
1. 「その他」→「天気の地点」を開く
2. 「いまの様子」に、いまの天気（「○℃・湿度○%・晴れ」など）と今日の最高気温が出る（「天気を受け取れませんでした」が出ない）
3. 「天気を取り直す」を押すと「天気を取り直しました」と出る
4. 「天気の付いた杯」が「○杯／○杯」で、92日以内に淹れた杯に天気が付いている

## C. 前の表の残り
1. `docs/iphone-check-3-3.md` の B の3〜6、C、D を確かめる
