# iPhoneでの確認表（ステップ3-4 分析の追加、Ver 3.4）

3-4で作った「再現性」「エイジング日誌」「用語辞典」を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.4）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 3.4 になりました」と、変わったことが3つ出る
3. 前からの豆・抽出・実験の記録が、そのまま残っている

## B. 再現性
1. 画面の下のタブ「分析」の「見る」に「再現性」がある。押すと「再現性」の画面が開く
2. 自分の記録で出ない（「同じ豆の袋を同じレシピで3杯淹れると」と出る）ときは、分析のいちばん下の「デモで見る」→「再現性」で見る
3. いちばん上に大きな数字（再現性スコア）と「★のブレ ±○（安定）」が出る
4. 豆ごとのカードの「★の管理図」で、点・真ん中の線・赤い点線が見分けられる。ライト・ダークどちらでも読める
5. 点を長く押すと「○杯目（日付） ★○」が出る
6. 文字が切れたり、画面が横にはみ出したりしない

## C. エイジング日誌
1. 「分析」→「エイジング日誌」を押す（記録が少なければデモで見る）
2. いちばん上の「豆ごとの飲み頃の山」に、豆の名前と「山 ○〜○日」が並ぶ
3. 豆のカードの図で、点線の枠（目安）と色の帯（山）が見分けられる
4. 「杯ごとの記録」を押すと開き、日数の順に杯が並ぶ。もう一度押すと閉じる
5. 自分のデータで、焙煎日を入れた豆で淹れたことのある豆の画面を開くと、「飲み頃」のカードの下に「エイジング日誌」の1行が出る。「日数ごとの★と記録を見る」で、その豆だけの日誌が開く

## D. 用語辞典
1. 「分析」→「抽出チャート」（デモでも可）のいちばん下の「TDS」の横の丸い「？」を押す。指で押しやすい
2. 用語辞典が開き、「TDS（濃度）」の項目に色が付いて画面の上に出る
3. 左上の「戻る」を押すと、抽出チャートに戻る
4. もう一度「？」から開き、項目の下の丸いボタン（例：「抽出収率（EY）」）を押してから「戻る」を押すと、抽出チャートに戻る
5. 1杯評価して、「次の1杯」のカードの「理論」の行の「？」を押すと理論カードが開き、「戻る」で評価の画面に戻る（評価は保存されたまま）
6. 「その他」→「用語辞典」で一覧が開き、いちばん上の「豆」などを押すとその区分に移る
