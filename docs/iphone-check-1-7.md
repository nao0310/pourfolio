# iPhoneでの確認表（ステップ1-7）

PCでは確かめられないこと（音・読み上げ・画面が消えないこと・ホーム画面のアプリとしての動き・片手での押しやすさ）を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。古い表示のときは、少し待ってからもう一度開き直す。

## A. トップ画面
1. いちばん上に「Pourfolio」とアイコンが出て、「準備中」の文字が消えている
2. 「今日の1杯」に前回の豆とレシピが出ている
3. 「豆の飲み頃」に、豆ごとの色の帯（青・緑・黄土色・赤）と黒い縦線が出ている
4. 一度も書き出していなければ、いちばん上に「記録を書き出しましょう」が出ている
5. いちばん下に「最後の書き出し：…」と「ホーム画面のアプリとして開いています」が出ている

## B. 毎日の1杯（30秒の確認）
1. 「今日の1杯」の「前回と同じで淹れる」（または「提案を入れて淹れる」）を押す
2. 抽出の画面で「スタート」を押す
3. 合図の音と読み上げが聞こえる。注いでいる間に画面が暗くならない
4. 「注ぐ」（茶色）と「待つ」（青）が見分けやすい。画面の下半分を片手の親指で押せる
5. 「落ち切った」を押す → 「実績の確認」→「保存する」→「味の評価」で★と一言を入れて「評価を保存する」
6. トップ画面に戻り、「直近の抽出」のいちばん上に「記録 ○秒」が出る。30秒以内か見る

## C. 画面の見た目（今回直したところ）
1. 豆の画面（「豆と在庫」→豆を押す）の「飲み頃」の帯に色が付いている（前は白い枠だけになっていた）
2. 豆の編集の「焙煎度」、器具の登録の「種類」のボタンで、文字が途中で折り返していない（「イタリアン」「ドリッパー」など）
3. 味の評価の「総合」の★5つが1行に並んでいる
4. 提案を入れた抽出の画面で、変えた項目の下に「提案で変更」と出ている
5. 左上の戻るリンク（「‹ トップ」など）や「あとで評価する」が、1回で押せる

## D. 書き出し
1. トップ画面の下の「データ」→「書き出す」→「"ファイル"に保存」で保存できる。トップ画面の「記録を書き出しましょう」が消える
2. 「CSVを書き出す」→「"ファイル"に保存」で、2つのファイルが保存される
3. 「ファイル」アプリでCSVを押すと、表の形で中身が見える（日本語が文字化けしていない）

## E. 暗い画面
1. iPhoneの「設定」→「画面表示と明るさ」→「ダーク」にして、トップ画面・抽出・味の評価を開く。文字が読みにくい所がない
2. 「ライト」に戻す
