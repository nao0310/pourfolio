# iPhoneでの確認表（ホーム画面のアプリでキーボードで欄が隠れる不具合の直し、Ver 3.6.4）

> **この確認表は使いません。** Ver 3.6.5 で直し方が変わったので、`docs/iphone-check-3-6-5.md` で確かめてください（D-187）。

Ver 3.6.3 では、Safari で開いたときは欄が見えるようになりましたが、ホーム画面のアプリでは隠れたままでした（画面写真をありがとうございました）。アプリでは、iPhone がキーボードの高さをアプリに伝えていないと見ています。そこで、伝わらないときは「画面の下半分がキーボードでおおわれる」と見込んで、欄を画面の上半分まで動かすようにしました（D-186）。この作業環境には Safari がないので、ここでは Chrome でまねて確かめただけです。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面に「新しい版（Ver 3.6.4）があります」が出たら「更新する」を押す（出なければ、アプリを閉じて開き直す）
2. 下のタブ「その他」→「データ（書き出し・保存）」を押し、「アプリの版とオフライン」が「Ver 3.6.4」になっている

## B. キーボードの点検（先にこれをお願いします）
1. 「データ（書き出し・保存）」の画面を下へなぞり、「キーボードの点検」の「ためしに押す欄」を押す
2. キーボードが出たまま2秒待つ。欄の下に数字の行が出る
3. その画面の画面写真を撮る（キーボードが出たまま）
4. キーボードの上の「✓」を押して閉じる
5. 画面写真を送ってください。「ホーム画面のアプリ：はい」と、「見える範囲がいちばん狭くなった分」の数字を見て、次の直し方を決めます

## C. レシピの編集（前回隠れた所）
1. 「その他」→「レシピ帳」→ レシピを1つ開いて「編集する」を押す
2. 画面を少し上へなぞって、「目標の抽出時間（落ち切りまで）」の欄が画面の下の端に来るようにする
3. その欄を押す。半秒ほどで、欄が欄の名前ごと画面の上半分まで上がり、キーボードに隠れない
4. 数字を1つ入れる。入れた数字が見える
5. キーボードの上の「v」（次の欄へ）を押してメモへ移る。メモもキーボードの上に見える
6. 「✓」を押して閉じる。下の「保存する」が画面のいちばん下にある
7. 保存しないで戻る

## D. ほかの画面（下のほうの欄を押して、欄が見えるか）
1. 「豆と在庫」→「豆を登録する」→ いちばん下の「メモ」
2. 豆を1つ開く →「次の自分への一言」、「おすそ分け・廃棄」の中の欄
3. 1杯淹れて「実績の確認」→ 下のほうの「TDS」「メモ」（いつもどおり淹れるときで大丈夫です）
4. 評価の画面 →「メモ」
5. 「その他」→「AIに相談」→「AIの答え」

## E. 副作用がないか
1. 画面の上のほうに見えている欄（豆の登録の「名前」など）を押す。画面の中身は動かない
2. 選ぶ欄（レシピの編集の「グラインダー」「注ぎ方」、豆の登録の「品種」など）を押す。画面の中身は見込みでは動かない。選ぶ部品が出て、選べる
3. 日付の欄（豆の登録の「焙煎日」など）を押す。日付を選べる
4. Safari で開いたときも、C の3と同じように欄が見える
5. 文字を入れたあと、ホーム・豆と在庫・分析・その他で、下のタブが画面のいちばん下にある

終わったら、B の画面写真と、うまくいかなかった番号を教えてください（全部できたら「全部できました」）。
