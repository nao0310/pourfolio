# iPhoneでの確認表（ステップ3-6 年間まとめ、Ver 3.6）

3-6で作った「年間まとめ（Coffee Wrapped）」を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号と、Fの数字を教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.6）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 3.6 になりました」と、変わったことが3つ出る
3. 前からの豆・抽出・評価の記録が、そのまま残っている

## B. まとめを開く
1. 下のタブ「分析」を押し、「年間まとめ」を押す
2. 茶色のカードに「2026年のコーヒー」と「1月1日〜（今日の日付）（今日まで）」、「○杯を振り返ります」が出る
3. 右上の「2026年」を押すと、記録のある年が並ぶ（去年の記録がなければ2026年だけ）
4. 「その他」→「豆と分析のほかの画面」にも「年間まとめ」がある

## C. めくる（片手で）
1. カードを左にスワイプすると、1枚ずつ次のカードに止まる（2枚飛ばない）
2. カードの右側を親指で押すと次へ、左の端のほうを押すと戻る
3. 下の「次へ」「前へ」でも動き、真ん中の「2 / 11」のような数が合っている
4. カードの下の「前へ」「次へ」と下のタブが、スクロールしなくても1画面に見えている
5. 長いカード（ベストなど）は、カードの中を上下にスクロールできる。スクロールしたときに、カードが横にずれない
6. 「ベスト」の★の高い3杯の行を押すと、その杯の評価の画面が開く。戻るとまとめに戻る

## D. 中身と見た目
1. 「飲んだ産地」の地図で、飲んだ国のあたりに点が出ている（エチオピアならアフリカの東、ブラジルなら南アメリカの東）
2. 地図に位置のない産地があれば、下に「地図に位置のない産地：…」と名前が出る
3. どのカードも、文字が切れたり、横にはみ出したりしない。「undefined」「NaN」が出ない
4. iPhoneの設定でダークモードとライトモードを切り替えても、どちらでも読める（表紙は茶色）

## E. 画像にする
1. 最後の「2026年のまとめ」のカードで「画像にする」を押す
2. カードの中に画像が出て、ボタンが「作り直す」に変わる
3. 「共有・保存」を押し、「画像を保存」を押すと、写真のアプリに入る
4. 写真のアプリで開くと、杯数・日数・豆・産地・平均の★・使った豆の数字が、カードと同じ

## F. 完了条件3（提案どおりに淹れた杯の評価が上がったか）
1. 「提案の効果」のカードを開く（評価のあとの提案どおりに淹れたことがなければ、このカードは出ない）
2. 大きな字の「★○ → ★○」と、「上がった」「同じ」「下がった」の回数を教えてください
   - 右の数が左より大きければ、完了条件3を満たしています

## G. ホームの知らせ（12月になってから）
1. 12月1日以降にトップ画面を開くと、「2026年のまとめができました」のカードが出る（今年10杯以上淹れていれば）
2. 「年間まとめを見る」を押すと、2026年のまとめが開く
3. 右上の「×」を押すとカードが消え、開き直しても出ない
- 12月より前はこのカードは出ません。Gは12月になってから確かめてください
