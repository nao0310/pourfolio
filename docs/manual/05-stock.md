# 5. 注文と買い足し

珈琲問屋で注文した豆をまとめて登録し、在庫が切れる前に次の注文の目安と、次に買う豆の候補を知らせます。

## 注文メールから登録する
1. メールアプリで珈琲問屋の「ご注文ありがとうございます」のメールを開く
2. 本文を長押しして「すべてを選択」→「コピー」を押す
3. Pourfolioで「豆と在庫」を押し、上の小さなボタンの並びの「注文メール」を押す
4. 「メールの本文」の枠を長押しして「ペースト」を押す
5. 「読み取る」を押す
6. 「3つの豆を読み取りました」と出て、下に「注文」（注文番号・注文日・送料）と豆が1つずつ並ぶことを確かめる
7. 銘柄や焙煎度が違っていたら、その場で直す。登録しない豆は「登録する」の印を外す
8. いちばん下の「入荷待ちとして登録（3袋）」を押す
9. 「豆と在庫」に戻り、「3袋を『入荷待ち』として登録しました」と出て、豆に「入荷待ち」の札が付いていれば完了

届いたら、「1. 豆を登録する」の「入荷待ちの豆が届いたとき」の手順で重さを入れます。

- 数量が2の豆は、2袋として別々に登録されます（袋ごとに残量と飲み頃を見るため）
- お菓子など豆以外の品物は登録しません。生豆（焼かない）は最初は印が外れています
- 同じメールをもう一度読み取ると「この注文は登録済みです」と出ます

## 買い物リストを見る
1. 「豆と在庫」の上の「買い物リスト」を押す（トップ画面の「そろそろ注文」の「買い物リスト」からも開けます）
2. いちばん上に「次の注文は11/25ごろ」「そろそろ注文：11/25までに」「今日、注文しましょう」のどれかが出る
   - 下に、手元の豆の量・入荷待ち・なくなる日・お届けの日数・休ませる日数が出る
3. 「次に買う候補」に、気になる豆（下の「気になる豆を貯める」）と、これまでに買った豆が並ぶ
   - 銘柄の横の札：「定番」は自分で飲んで★の付いた豆、「開拓」はまだあまり飲んでいない産地や精製の豆
   - 「予想★3.8」は、その豆にどれくらいの★が付きそうかの予想。その下に理由が出る（「この豆の★平均 4.2（10杯）」「まだ飲んだことのない産地（パナマ）」など）
   - 「焙煎度はハイ（…）」は、おすすめの焙煎度とその理由
   - 「店のページ」を押すと、登録した商品ページのURLが開く（URLを入れた豆だけ）
4. 注文する豆の印を付ける
5. 「注文メモ」に「・ガテマラSHB ハイロースト 生豆時300g 1,740円（前回 ★4.5）」のようなメモができる
   - 量は、飲むペースの4週間分を印を付けた豆の数で分け、生豆時100g単位に切り上げた目安。最後の行に「量は飲むペースの28日分を2種で分けた目安」と出る
   - 値段に「約」が付いているのは、100gの値段から計算した見積もり
6. 「メモをコピー」を押し、「注文メモをコピーしました」と出たら、メモアプリなどに貼っておく
7. 注文は珈琲問屋のサイトで、メモを見ながら行う

## 気になる豆を貯める
1. 珈琲問屋のサイトで気になる豆の商品ページを開き、ページの文章を全部選んで「コピー」を押す
2. Pourfolioで「豆と在庫」を押し、上の小さなリンクの並びの「気になる豆」を押す（買い物リストの「気になる豆を足す・見る」からも開けます）
3. 「珈琲問屋の商品ページから入れる」の枠を長押しして「ペースト」を押す。商品ページのURLがあれば下の欄に貼る
4. 「読み取る」を押す
5. 「入れた項目：銘柄・生産国・精製・焙煎度・価格」と出て、下の「気になる豆を足す」の欄に入ったことを確かめる（手で入れてもよい。必須は銘柄だけ）
6. 「足す」を押す
7. 画面の上に「『○○』を足しました」と出て、「まだ買っていない豆」に予想★とおすすめの焙煎度が出れば完了

直したいときは「直す」、いらなくなったら「消す」を押します。

## 気になる豆を買ったとき
1. 珈琲問屋のサイトで注文する
2. 「気になる豆」の画面で、その豆の「買った」を押す
3. 豆の登録の画面が開き、上に「気になる豆『○○』の内容を入れました」と出る（状態は「入荷待ち」、焙煎度はおすすめのもの）
4. 焙煎度・表記重量・価格を、注文した内容に直す（表記重量を200gにすると、価格も200gの値段に変わります）
5. いちばん下の「登録する」を押す
6. 気になる豆の画面に戻ると、その豆は「購入済み」に移っている

届いたら、「1. 豆を登録する」の「入荷待ちの豆が届いたとき」の手順で重さを入れます。

## 送料無料ラインのまとめ買い
1. 買い物リストの「送料無料のまとめ買い」で「送料の設定」を押す
2. 珈琲問屋の案内を見て、「送料」と「送料無料ライン」を入れる
3. 冷凍庫に1杯分の袋がいくつ入るかを「冷凍庫に入る袋の数」に入れる（下に、いま冷凍中の袋の数が出ます）
4. 「保存」を押し、「保存しました」と出ることを確かめる
5. 「次に買う候補」で注文する豆に印を付ける
6. 「合計 1,800円。送料無料まで、あと1,200円」のように出て、その下にラインに届く豆が並ぶ
   - 「冷凍庫に入ります（6袋分）」と出る豆は、1杯分ずつ冷凍すれば冷凍庫に入る量です
7. 足したい豆の「足す」を押すと、印が付いて注文メモに加わる

## コツ
- 「開拓」の点：まだ飲んだことのない産地は＋0.5、精製は＋0.3。飲んだのが5杯より少なければその半分、5杯からは0です。好きな豆ばかりにならないように、ときどき新しい豆が上に来ます
- おすすめの焙煎度は、①その産地の焙煎度比較の結果 → ②その産地で3杯以上飲んだ焙煎度の中で★がいちばん高いもの → ③買ったことのある豆はその豆で★がいちばん高い焙煎度か前回の焙煎度、気になる豆は店の標準、の順に決めます
- 気になる豆と同じ銘柄を前に買っていれば、1つにまとめて自分の★で予想します
- 注文の目安日は「在庫がなくなる日 − お届けの日数 − 休ませる日数」です。休ませる日数は、次に買いそうな豆の焙煎度で決まります（シティなら1日、ミディアム・ハイなら2日）
- お届けの日数は、最初は7日で計算します。注文日と到着日のある注文が2回以上になると、実際にかかった日数に切り替わります
- お届けの日数を変えたいときは、買い物リストのいちばん下の「注文から届くまで」を直して「保存」を押す
- 目安日は、2週間で2杯以上淹れると表示されます
- 手元の豆の量には、冷凍している袋も入ります
- 足した豆は、飲み頃のうちに1杯分ずつ冷凍しておくと長く楽しめます（「1. 豆を登録する」の「小分けにして冷凍する」）

## 注意
- メールの名前・住所・電話番号は読み取らず、保存もしません。メールの本文も保存しません
- 送料と送料無料ラインは、アプリが店のサイトから読むことはありません。店の案内が変わったら入れ直してください
- 価格を入れていない候補は、まとめ買い案に使いません
- 印を付けた豆を「もう1袋」買う案は出しません
