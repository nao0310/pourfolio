# 9. 焙煎度を飲み比べる

同じ豆の焙煎度違い（珈琲問屋の焙煎度違いのお試しセットなど）を、同じレシピで淹れて飲み比べます。ブラインド（どのカップか分からないまま評価）にでき、結果から「この産地はハイが好き」のように好きな焙煎度がわかります。

## 用意するもの
- 比べる豆を2〜4袋、豆として登録しておく（「1. 豆を登録する」）。同じ銘柄にして、焙煎度だけを変えて登録する
- カップを袋の数だけ。ブラインドにするときは、焙煎度を書く付せん（またはマスキングテープ）も
- 量の少ないレシピ（粉10g前後）があると、何杯も飲みやすい（「2. 器具とレシピを登録して淹れる」）

## 始める
1. 画面の下のタブ「豆と在庫」を押す
2. 上のボタンの並びの「焙煎度の飲み比べ」を押す（豆の画面の「焙煎度を飲み比べる」からも開ける）
3. 「新しく始める」に、焙煎度違いがそろっている豆が「エチオピア イルガチェフェ（ミディアム・ハイ・シティ）」のように出ていれば、それを押す。下の「比べる豆」に印が付く
4. 組が出ていないときは、「比べる豆」で比べたい袋を2〜4つ押して印を付ける
5. 「レシピ」で淹れるレシピを選ぶ
6. ブラインドにするときは「ブラインドにする」に印が付いたままにする（最初から付いている）
7. 「飲み比べを始める」を押す。飲み比べの画面に変わり、「1. 淹れる」に袋が焙煎度の浅い順に並べば完了

## 淹れる
1. 「1. 淹れる」のいちばん上の袋の「淹れる」を押す
2. 抽出の画面に変わる。上に「焙煎度の飲み比べで淹れています」と出て、「豆」にその袋が選ばれていることを確かめる
3. いつもと同じように淹れて（タイマーでも「タイマーを使わずに記録する」でもよい）、「実績の確認」で「保存する」を押す
4. 味の評価の画面には行かず、飲み比べの画面に戻る。その袋の右が「淹れた」に変わる
5. ブラインドにするときは、淹れたカップの底（またはコースター）に、焙煎度を書いた付せんを貼る
6. 残りの袋も、同じように「淹れる」から淹れる
7. 全部の袋が「淹れた」になると、「2. 飲み比べる」と「3. 答え合わせ」が出る

## 飲み比べる（ブラインド）
1. 底を見ないようにカップを混ぜて並べ、左から1番、2番…とする
2. 「カップ 1」から順に飲み、☆を押して★を付ける。一言とメモは入れなくてもよい。押すとすぐに保存される
3. 全部のカップに★を付ける
4. 「3. 答え合わせ」で、カップの底を見て、「カップ 1」「カップ 2」…の欄でそれぞれ底に書いてあった焙煎度を選ぶ
5. 「結果を見る」を押す
6. 「結果」に「1位　ハイ　エチオピア…　カップ3　★5」のように★の多い順に並び、その下に「エチオピアはハイが好き（飲み比べ1回）」と出れば完了

ブラインドにしないときは、「2. 飲み比べる」に袋の名前が出るので、袋ごとに★を付けて「結果を見る」を押します。

## 結果を使う
- 結果の袋の名前を押すと、その1杯の評価の画面が開く。香味や強さと好みを足したり、評価を直したりできる
- 「焙煎度の飲み比べ」の画面の「わかった好み」に、産地ごとの好きな焙煎度と、焙煎度ごとの★の平均が出る
- 豆の画面の「焙煎度の飲み比べ」に「エチオピアはハイが好き（飲み比べ1回）。次の注文は「ハイ」がおすすめです」と出る
- 買い物リストの候補にも、その産地の豆なら好きな焙煎度が出る。今の焙煎度と違うときは「次は「ハイ」で」と出る

## コツ
- 淹れている間にカップが冷めるので、全部淹れてから少し待ち、同じくらいの温度で飲み比べると比べやすい
- 1回で決めず、何回か飲み比べると「わかった好み」の回数が増えて確かになる
- 途中でやめても、トップ画面に「焙煎度の飲み比べの途中です」と出る。「続きに戻る」で続きから進める

## 注意
- 答え合わせで同じ焙煎度を2つのカップに選ぶと、「同じ焙煎度を2つのカップに選んでいます」と出て進めない
- 全部のカップに★を付けないと、「どのカップにも★を付けてください」と出て結果を見られない
- 飲み比べで淹れた杯は、トップ画面の「まだ評価していない1杯」と「冷めた味を評価しませんか」には出ない（ブラインドを崩さないため）
- 好きな焙煎度は、生産国（豆の「産地」の国）ごとにまとめる。国を入れていない豆は銘柄ごとにまとめる
- 「この飲み比べをやめる」を押すと飲み比べは消えるが、淹れた抽出と評価は残る
