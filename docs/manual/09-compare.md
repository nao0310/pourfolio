# 9. 実験する（飲み比べ・トライアングル・最適化）

豆や条件を、伏せたまま飲み比べて、好みや違いを確かめます。4つのやり方があります。
- 豆の飲み比べ：焙煎度違い（珈琲問屋の焙煎度違いのお試しセットなど）や銘柄違いの袋を、同じレシピで飲み比べる。好きな焙煎度がわかる
- 条件の飲み比べ：同じ豆・同じレシピで、挽き目・湯温・比率のどれか1つだけ変えた2杯を飲み比べる
- トライアングルテスト：3つのカップから1つだけ違うカップを当て、違いが本当に分かるかを確かめる
- 最適化：挽き目と比率の範囲を決めると、★を付けた杯から「次に試すとよい条件」が出る

## 開き方
1. 画面の下のタブ「豆と在庫」を押す
2. 上の小さなリンクの並びの「実験」を押す（「その他」の「実験」、豆の画面の「実験」の「飲み比べる」からも開ける）
3. 「実験」の画面が開く。上から「次に試す実験」「わかったこと」「新しく始める」「最適化」「これまでの実験」の順に並ぶ

## 用意するもの
- カップを、淹れる杯の数だけ。トライアングルテストは4つ
- ブラインドにするときは、カップの底に書く付せん（またはマスキングテープ）
- 量の少ないレシピ（粉10g前後）があると、何杯も飲みやすい（「2. 器具とレシピを登録して淹れる」）

## 豆の飲み比べを始める
1. 「新しく始める」の「比べるもの」で「豆」を押す
2. 焙煎度違いがそろっている豆が「エチオピア イルガチェフェ（ミディアム・ハイ・シティ）」のように出ていれば、それを押す。下の「比べる豆」に印が付く
3. 組が出ていないときは、「比べる豆」で比べたい袋を2〜4つ押して印を付ける（銘柄が違う袋どうしでもよい）
4. 「レシピ」で淹れるレシピを選ぶ
5. ブラインドにするときは「ブラインドにする」に印が付いたままにする（最初から付いている）
6. 「飲み比べを始める」を押す。飲み比べの画面に変わり、「1. 淹れる」に袋が焙煎度の浅い順に並べば完了

## 条件の飲み比べを始める
1. 「新しく始める」の「比べるもの」で「条件」を押す（「次に試す実験」の「この飲み比べを始める」を押すと、中身が入った状態で開く）
2. 「豆」と「レシピ」を選ぶ
3. 「変える条件」で「挽き目」「湯温」「比率」のどれかを押す
4. 「変える幅」で「2目盛り細かく」「3℃上げる」などを選ぶ。下に「いつもの1杯と、挽き目 24 → 22（2目盛り細かく）を比べます」のように出る
5. 予想があれば「予想」に書く（書かなくてもよい）
6. 「飲み比べを始める」を押す。「1. 淹れる」に「いつもの（挽き目 24）」と「挽き目 22」が並べば完了

## 淹れる（豆の飲み比べ・条件の飲み比べ）
1. 「1. 淹れる」のいちばん上の「淹れる」を押す
2. 淹れる画面に変わる。上に「条件の飲み比べで淹れています」「このカップ：挽き目 22」のように出て、「計画」の数字が変えた条件になっていることを確かめる
3. いつもと同じように淹れて（タイマーでも「タイマーを使わずに記録する」でもよい）、「実績の確認」で「保存する」を押す
4. 味の評価の画面には行かず、実験の画面に戻る。そのカップの右が「淹れた」に変わる
5. ブラインドにするときは、淹れたカップの底（またはコースター）に、焙煎度や条件を書いた付せんを貼る
6. 残りも、同じように「淹れる」から淹れる
7. 全部が「淹れた」になると、「2. 飲み比べる」と「3. 答え合わせ」が出る

## 飲み比べる（ブラインド）
1. 底を見ないようにカップを混ぜて並べ、左から1番、2番…とする
2. 「カップ 1」から順に飲み、☆を押して★を付ける。一言とメモは入れなくてもよい。押すとすぐに保存される
3. 全部のカップに★を付ける
4. 「3. 答え合わせ」で、カップの底を見て、「カップ 1」「カップ 2」…の欄でそれぞれ底に書いてあった焙煎度（または条件）を選ぶ
5. 「答え合わせをする」を押す
6. 「結果」に★の多い順に並べば完了。条件の飲み比べでは、上に「挽き目を2目盛り細かく：★1つ良くなった（★3 → ★4）」のように出る

ブラインドにしないときは、「2. 飲み比べる」にカップの名前が出るので、カップごとに★を付けて「結果を見る」を押します。

## トライアングルテスト
1. 「新しく始める」の「比べるもの」で「トライアングル」を押す
2. 「2つの豆」か「条件を1つ変える」を押す
3. 「2つの豆」なら、比べる豆をちょうど2袋押して印を付ける。「条件を1つ変える」なら、豆・変える条件・変える幅を選ぶ
4. 「レシピ」を選び、「トライアングルを始める」を押す。「1. 淹れる」に「A：…」「B：…」が並べば完了
5. AとBを1杯ずつ「淹れる」から淹れ、それぞれ2つのカップに分ける。カップの底に「A」か「B」を書いた付せんを貼る
6. 「2. 当てる」の3行の手順（「Aを2つ、Bを1つ並べます」のように出る）のとおりに3つのカップを選び、底を見ずに混ぜて、左から1〜3番にする。残りの1つはあとで飲む
7. 3つとも飲んで、「1つだけ違うと思うカップ」で番号を押す
8. カップの底を見て、「3. 答え合わせ」で1つだけだったカップの番号を押す。好きな方があれば「A」「B」「同じくらい」を押す（押さなくてもよい）
9. 「答え合わせをする」を押す。「結果」に「当たり！」か「はずれ」と、「1回中1回当たり。まだ偶然と区別できません」のような成績が出れば完了
10. 続けるときは「同じ組でもう1回」を押す。同じ組の成績が積み重なる

## 最適化
1. 「実験」の画面の「最適化」で「最適化を始める」を押す（豆の画面の「実験」の「最適化する」からも開ける）
2. 「豆」と「レシピ」を選ぶ（挽き目が数字のレシピを選ぶ）。「挽き目の範囲」と「比率の範囲」に、レシピのまわりの範囲が入る。変えたいときは数字を直す
3. 湯温も動かすときは「湯温も動かす」に印を付けて範囲を入れる（杯数が多く要る）
4. 「最適化を始める」を押す。最適化の画面に変わり、「次の1杯」に「挽き目 20・比率 1:17.5」のように出れば完了
5. 「この条件で淹れる」を押して淹れ、いつものように★を付ける
6. もう一度「実験」→「最適化」の一覧からその最適化を開くと、★を付けた杯から「次の1杯」が選び直されている
7. 「今のいちばん」に、今までで予想がいちばん良い条件が出る。「この条件で淹れる」でその条件で淹れられる
8. 終わったら「この最適化を終える」を押す。一覧で「終えた」になる（「この最適化を続ける」で戻せる）

## 結果を使う
- 結果の名前を押すと、その1杯の評価の画面が開く。香味や強さと好みを足したり、評価を直したりできる
- 「実験」の画面の「わかったこと」に、産地ごとの好きな焙煎度、条件の飲み比べのまとめ（「挽き目を細かく：2回のうち2回良くなった」）、トライアングルの成績が出る
- 豆の画面の「実験」に「エチオピアはハイが好き（飲み比べ1回）。次の注文は「ハイ」がおすすめです」や、その豆の条件の飲み比べのまとめが出る
- 買い物リストの候補にも、その産地の豆なら好きな焙煎度が出る

## コツ
- 淹れている間にカップが冷めるので、全部淹れてから少し待ち、同じくらいの温度で飲み比べると比べやすい
- 「次に試す実験」は、直近に淹れた豆で出る。前の1杯のダイヤルイン提案や、「条件と評価」で★と一緒に動いている条件を、1つだけ変えて確かめる案が出る
- トライアングルテストは5回ほど続けると、違いが分かっているかがはっきりする
- 最適化の「予想の地図」は、★を付けた杯から予想した★。「次」が次に試す所、「済」が試した所。表は横に動かせる
- 途中でやめても、ホームに「条件の飲み比べの途中です」のように出る。「続きに戻る」で続きから進める

## 注意
- 答え合わせで同じものを2つのカップに選ぶと、「同じ焙煎度を2つのカップに選んでいます」（条件の飲み比べでは「同じ条件を…」）と出て進めない
- 全部のカップに★を付けないと、「どのカップにも★を付けてください」と出て結果を見られない
- 挽き目が数字でないレシピでは、挽き目の飲み比べと最適化はできない（「このレシピの挽き目が数字ではありません」と出る）
- 飲み比べとトライアングルで淹れた杯は、ホームの「まだ評価していない1杯」と「冷めた味を評価しませんか」には出ない（ブラインドを崩さないため）。トライアングルの杯は結果の名前を押すと評価できる
- 最適化で淹れた杯は、ふつうの1杯と同じように評価の画面に進む。★を付けないと次の条件に使われない
- 好きな焙煎度は、生産国（豆の「産地」の国）ごとにまとめる。国を入れていない豆は銘柄ごとにまとめる
- 「この実験をやめる」「この最適化をやめる」を押すと消えるが、淹れた抽出と評価は残る
