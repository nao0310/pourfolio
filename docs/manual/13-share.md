# 13. 共有・QR・印刷

レシピをQRやリンクで人に渡す・取り込む、キャニスターのQRから淹れる、レシピカードや月次レポートを印刷する、1杯を1枚の画像にする方法です。どれもサーバーには何も送りません。

## レシピを共有する（QR・リンク）
1. 画面の下のタブ「淹れる」を押す
2. 共有したいレシピの「共有・印刷」を押す
3. 「レシピを共有」の画面に変わり、真ん中にQRコードが出る
4. 豆の情報も渡したいときは、「豆の情報を添える（任意）」で豆を選ぶ（QRが作り直される）
5. 相手には次のどれかで渡す
   - 相手のPourfolioの「QRを読む」で、このQRを読んでもらう
   - 「共有する（メッセージ・AirDropなど）」を押して、リンクを送る
   - 「リンクをコピー」を押し、「リンクをコピーしました」と出たら、メッセージなどに貼り付ける

## 共有されたレシピを取り込む
1. 画面の下のタブ「その他」→「QRを読む」を押す
2. 「カメラで読む」を押す。初めてのときは「カメラへのアクセスを求めています」と出るので「許可」を押す
3. 枠の中にQRを写す
4. 「共有されたレシピ」の画面に変わり、粉量・湯量・注湯の流れ・挽き目・豆が出る
5. 中身を確かめて「レシピ帳に取り込む」を押す
6. 「「（レシピの名前）」をレシピ帳に入れました」と出れば完了
7. 器具は選ばれていないので、「器具を選ぶ（編集）」を押して自分のグラインダー・ドリッパーを選び、下の「保存」を押す

- リンクをもらったときは、リンクを長押しして「コピー」→「QRを読む」の画面の「リンクを貼り付けて開く」の欄を長押しして「ペースト」→「開く」を押す
- 相手の豆の情報・挽き目・ドリッパーは、取り込んだレシピの「メモ」に入っている

## キャニスターのQRから淹れる
1. 画面の下のタブ「豆と在庫」を押し、豆を選ぶ
2. 下のほうの「キャニスター用QR」の「QRを表示する」を押す
3. 「ラベルを印刷」を押すと「キャニスターのラベル」の画面に変わる。印刷はこのページの「印刷する」の手順と同じ
4. 印刷したラベルをキャニスターに貼る
5. 淹れるときは、「その他」→「QRを読む」（ホームの「QRを読む（キャニスター・共有レシピ）」でもよい）→「カメラで読む」でラベルのQRを写す
6. 淹れる画面に変わり、上に「★がいちばん高かった杯：…」と出て、その豆が選ばれていれば完了（まだ★を付けていない豆は「…の最初のレシピ」）

## レシピカード・ラベル・月次レポートを印刷する（PDFにする）
1. レシピカードは、レシピの「共有・印刷」→ いちばん下の「レシピカードを開く」を押す
2. 月次レポートは、タブ「分析」→「月次レポート」を押し、「月」で見たい月を選ぶ
3. レシピカードとラベルは「名刺（91×55mm）」か「A6（105×148mm）」を押して大きさを選ぶ（見本が変わる）
4. 「印刷する」を押す
5. プリンターで印刷するときは、プリンターを選んで右上の「印刷」を押す
6. PDFにするときは、印刷の画面の見本を2本指で広げる → 右上の共有ボタン →「"ファイル"に保存」を押す

## 1杯を1枚の画像にする
1. 評価の画面（評価を保存したあと、またはホームの「直近の抽出の記録」から開く）のいちばん下の「1枚の画像にする」を見る
2. 自分のメモも載せたいときだけ「メモも入れる」を押して印を付ける
3. 「画像を作る」を押す
4. 豆・条件・★・注湯の流れが入った縦長の画像が出る
5. 「共有・保存」を押し、「画像を保存」を押すと写真アプリに入る（SNSに送ることもできる）

## コツ
- レシピカードにもQRが入っているので、カードを渡せば相手は「QRを読む」で取り込める
- 月次レポートは、記録した月ならどの月でも選べる。先月と比べた「好みの変化」も出る

## 注意
- iPhoneでは、標準のカメラアプリでQRを読まずに、必ずPourfolioの「QRを読む」で読む。標準のカメラだとSafariで開き、ホーム画面のPourfolioとは別の場所になるため、記録や豆が出ない
- 共有リンクに入るのは、レシピの数字と注ぎ方、選んだ豆の基本情報（銘柄・店・産地・焙煎度など）だけ。メモ・価格・日付は入らない
- 「QRを読む」では、Pourfolioの画面と共有リンクだけを開く。ほかのQR（お店のサイトなど）は文字を見せるだけで開かない
- キャニスターのラベルは豆ごとに違う。豆を新しい袋に替えて登録し直したら、ラベルも作り直す
