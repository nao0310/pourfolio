# 0. はじめに（ホーム画面に追加する）

iPhoneでPourfolioを「ホーム画面のアプリ」として使えるようにします。

## 手順
1. iPhoneの「Safari」で https://nao0310.github.io/pourfolio/ を開く
2. 画面下の「共有」ボタン（四角から上向き矢印が出ているマーク）を押す
3. メニューを上にスクロールして「ホーム画面に追加」を押す
4. 名前が「Pourfolio」になっていることを確かめ、右上の「追加」を押す
5. ホーム画面にできたコーヒーカップのアイコンを押して開く
6. トップ画面の下の「データ」を押し、いちばん下の「保存テストを開く」を押す。値を入力して「保存する」を押す
7. アプリを閉じて（画面の下から上へスワイプし、Pourfolioを上へはじく）、ホーム画面のアイコンから開き直す
8. 「データ」→「保存テストを開く」を押し、手順6の値が残っていれば成功

## コツ
- 保存テストの「開き方」が「ホーム画面のアプリ」になっていれば、正しく追加できています
- Safariで開いている間は、トップ画面のいちばん上に赤い枠の「ホーム画面に追加して使ってください」が出ます。ホーム画面のアプリから開くと消えます

## 通信がないところで使う
1. 通信できる場所で一度アプリを開く（全部の画面がiPhoneの中に保存されます）
2. トップ画面の下の「データ」を押し、「オフライン」の欄が「準備済み：通信がなくても開けます」になっていることを確かめる
3. これで、機内モードや電波のないところでも、全部の画面を開いて記録できます

## 新しい版に切り替える
1. アプリが新しくなると、画面のいちばん上に「新しい版があります」と出る
2. 右の「更新する」を押す
3. 画面が読み込み直され、新しい版になる（記録はそのまま残ります）

- 抽出のタイマーや実績の確認の途中では出ません。保存してから、ほかの画面で押してください
- 出ないときは、アプリを閉じて開き直すか、裏に回して10分ほどたってから戻ると確かめ直します

## 注意
- **必ずホーム画面に追加したアプリから使ってください。** Safariで開くだけだと、しばらく開かないうちに記録データが消えることがあります
- 記録データはこのiPhoneの中にだけ保存されます。定期的に書き出し（バックアップ）してください（手順は「7. 書き出し・復元」）
