# 12. AIに相談する

記録の要約と質問を1つの文章にしてコピーし、手元のチャットAI（ChatGPT・Claude・Geminiなど）に貼って相談します。AIの答えのレシピを貼り戻すと、そのまま淹れられます。アプリから自動でどこかに送ることはありません。

## 相談の文章をコピーする
1. 画面の下のタブ「その他」を押す
2. 「AIに相談」を押す
3. 「1. 質問を選ぶ」で、次のどれかを押す
   - 「次の1杯で何を変える？」
   - 「この豆に合う淹れ方は？」（押すと「豆」が出るので、相談したい豆を選ぶ）
   - 「次に珈琲問屋で何を買う？」
4. 伝えたいことがあれば「付け足すこと（任意）」に書く（例：朝は時間がないので3分以内にしたい）
5. 「2. コピーしてAIに貼る」の「文章をコピーする」を押す
6. 「コピーしました（○文字）」と出れば完了
7. チャットAIのアプリを開き、入力欄を長押しして「ペースト」を押し、送る

- コピーする中身は「コピーする文章を見る」を押すと確かめられる。直近14杯の表（豆・粉・湯・比率・湯温・挽き目・時間・★・ちょうど良さ・一言）、好みの上位と下位、手元の豆、器具が入る
- 「コピーできませんでした」と出たときは、選ばれた文章を長押しして「コピー」を押す

## AIの答えで淹れる
「次の1杯で何を変える？」と「この豆に合う淹れ方は？」のときは、答えの最後に「【提案レシピ】」が付くように頼んであります。
1. チャットAIの答えを長押しして「コピー」を押す（「【提案レシピ】」の部分を含める）
2. Pourfolioの「AIに相談」に戻り、「3. AIの答えを貼り戻す」の「AIの答え」を長押しして「ペースト」を押す
3. 「読み取る」を押す
4. 「読み取りました」と出て、粉量・湯量・湯温・挽き目と理由が並ぶ。読めなかった項目は「—」
5. 「淹れる豆」を確かめる（答えの豆の名前から選んである。見つからなければ自分で選ぶ）
6. 「この計画で淹れる」を押す
7. 淹れる画面に変わり、上に「AIの提案：（レシピの名前）」と出れば完了

## コツ
- 「付け足すこと」に、今の悩み（例：「後味が渋い」）を書くと、答えが具体的になる
- 注ぎ方は、その豆でいちばん★が高かった杯（なければ前回の杯、まだ淹れていなければ最初のレシピ）を土台にし、読み取った数字だけを入れる
- AIの答えは、アプリの提案（「4. 提案を読む」）と同じく、1回に1つだけ変えると結果が読みやすい

## 注意
- 自由に書いたメモは、相談の文章に入れない（人に見せたくないことを書いていることがあるため）
- 貼るかどうかは自分で決める。AIのサービスに送った文章は、そのサービスの決まりで扱われる
- AIの湯量は「お湯の量」として読む。アイスにしたいときは、淹れる画面で「アイス（急冷）」を押す
- 「次に珈琲問屋で何を買う？」の答えは読み取らない。買い物リストを見ながら注文する（「5. 注文と買い足し」）
