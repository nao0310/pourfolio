# 15. 用語辞典を見る

TDS・抽出収率・嗜好スコアなど、提案や分析の画面に出てくる言葉の意味と、このアプリでの使われ方を見ます。

## 言葉の横の「？」から開く
1. 分析の画面（抽出チャート・条件と評価・嗜好プロファイル・生活との関係・再現性・エイジング日誌・ダイヤルインの道のり）や、実験・最適化の画面で、言葉の横の丸い「？」を押す
2. 用語辞典が開き、その言葉の項目に色が付いて画面のいちばん上に出る
3. 太字の1行が意味、その下が説明、左に線のある「このアプリでは：」がこのアプリでの使われ方
4. 下の丸いボタン（関連する言葉）を押すと、その言葉の項目に移る
5. 画面の左上の「戻る」を押すと、「？」を押した元の画面に戻る

## 評価のあとの提案から開く
1. 評価を保存すると出る「次の1杯」のカードで、「理論」の行の「？」を押す
2. 直し方に合った理論カードが開く（挽き目を変える案なら「挽き目と時間」、粉量や湯量を変える案なら「比率で濃さを変える」、ほかは「抽出の足りない・進み過ぎ」）
3. 「戻る」を押すと評価の画面に戻る

## 一覧から探す
1. 画面の下のタブ「その他」を押す
2. 「用語辞典」を押す（分析の画面のいちばん下の「用語辞典」からも開けます）
3. いちばん上の「理論カード」「抽出の数字」「豆」「味の評価」「分析と実験」を押すと、その区分に移る

## コツ
- 理論カードは、酸っぱい・苦いの理由や、挽き目・湯温・比率の効き方の短い説明です。提案の理由がよく分からないときに読んでください

## 注意
- 評価の入力の途中（ちょうど良さなど）には「？」を出していません。移ると入れかけの値が消えるためです。評価を保存したあとの提案のカードから開いてください
