# 10. 分析を見る

記録から、好きな味と直し方の手がかりを見ます。記録が少ないうちは「あと○杯で表示します」と出て、途中の結果は出しません。どの画面も「一緒に動いている」ことを示すだけで、原因とは限りません。

## 分析の画面を開く
1. 画面の下のタブ「分析」を押す（トップ画面の「分析を見る」からも開けます）
2. 「これまでの記録」に、淹れた杯・TDS付きの杯・豆の数・今日の杯数とカフェインが出る
3. 「見る」に7つの画面が並ぶ。右の札が「見られます」なら中身が出る。「準備中」の画面は、下の文に「あと○杯で表示します（いま○杯）」と出る
4. 見たい画面の名前を押す

## デモで見る（記録が少ないとき）
1. 分析の画面のいちばん下の「デモで見る」を押す
2. 画面の上に点線の枠で「デモデータを表示しています」と出れば完了。作り話の記録（豆8袋・80杯）で、7つの画面がどう見えるかを確かめられる
3. デモのまま、ほかの分析の画面に移れる（どの画面にも上の枠が出ます）
4. 終わったら、枠の中の「自分のデータに戻る」を押す
- デモは見るだけで、あなたの記録には何も書き込みません

## ダイヤルインの道のり
豆ごとに、何を変えて★がどう動いたかを見ます。1つの豆で3杯から出ます。
1. 「ダイヤルインの道のり」を押す
2. 「豆」で見たい豆を選ぶ（最後に淹れた豆が最初に選ばれている）
3. 「自己ベスト」と、ベストの9割（★5なら★4.5以上）に初めて届いた「○杯目」が出る
4. 折れ線は何杯目（横）と★（縦）。点の色は★の濃さ
5. 下に杯ごとに「変えた：挽き目 24→23、湯温 +2℃」のように前の杯から変えた条件、「使った提案」、「雑味」が並ぶ
- いちばん上の「ダイヤルインの速さ」は、3杯以上淹れた豆が2つ以上あると出る

## 抽出チャート
濃さ（TDS）と抽出収率のどこに自分の好きな杯があるかを見ます。TDSを入れた杯から出ます。
1. 「抽出チャート」を押す
2. 縦がTDS（%）、横が抽出収率（%）。点の色が★で、下に「★1〜★5」の色見本がある。中が白い点は、抽出液を量らずに見積もった杯
3. 点線の四角が昔からの理想（収率18〜22%・TDS 1.15〜1.35%）、斜めの点線が比率（1:14〜1:17）
4. TDSを入れて★を付けた杯が10杯たまると、塗った四角で「自分の好きゾーン」（★4以上の杯の真ん中の範囲）が出る
5. 下の「自分の好きゾーン」に範囲の数字と、「直近の杯は好きゾーンより濃い（湯を増やす）」のような直す方向が出る
- 点を長く押す（PCではマウスを乗せる）と、日付・豆・★・TDS・収率が出る

## 条件と評価
挽き目・湯温・比率・焙煎後日数のどれが★と一緒に動いているかを見ます。★を付けた杯が20杯から出ます。
1. 「条件と評価」を押す
2. いちばん上に「いちばん一緒に動いている条件」が出る（例：「挽き目：はっきりした傾向：小さいほど★が高い」）
3. 条件ごとに、点（1杯）と傾向の破線が出る。「ほとんど関係が見えない」「弱い傾向」「はっきりした傾向」と、相関の数字が出る
4. いちばん下の「飲み頃カーブ」に、焙煎度ごとの焙煎後日数と★の平均が出る。同じ焙煎度で5袋たまると線になり、「いちばん★が高いのは 12〜15日」のように出る
- 挽き目は、いちばん多く使ったグラインダーの杯だけで比べます（目盛りはグラインダーごとに違うため）
- 確かめたいときは、いちばん上の「飲み比べで確かめる」を押す。「実験」の画面の「次に試す実験」に、1つだけ変えて飲み比べる案が出る（「9. 実験する」）

## 嗜好プロファイル
産地・精製・焙煎度・品種ごとの好みを見ます。★を付けた杯が30杯から出ます。
1. 「嗜好プロファイル」を押す
2. 「産地」「精製」「焙煎度」「品種」ごとに、点数の高い順に並ぶ。横の棒と数字が嗜好スコア、下に「20杯・平均★3.9・信頼度高」
3. 「産地×焙煎度」「精製×焙煎度」の表は、マスの濃さが嗜好スコア、数字が杯数。「—」はまだ飲んでいない組み合わせ
4. いちばん下の「味の好みの位置」に、「酸味：強さ 7〜9 が好き」のように項目ごとの好きな強さが出る（詳しい評価が20件から）
- 嗜好スコアは、杯数の少ない区分を全体の平均に寄せた★です。1杯だけ飲んだ豆が1位にならないようにしています

## 生活との関係
時間帯・曜日・気分・天気・季節で、★がどう違うかを見ます。★を付けた杯が30杯から出ます。
1. 「生活との関係」を押す
2. いちばん上に「★のある80杯から。天気の付いた杯は80杯です」のように出る
3. 「時間帯」「曜日」「気分」「ホットとアイス」「気温」「湿度」「天気」「季節」ごとに、横の棒と数字（嗜好スコア）、下に「74杯・平均★3.49」が出る。上の文に「20〜28℃がいちばん高め」や「時間帯による★の差は、ほとんどありません」のようにまとめが出る
4. 杯が3杯に届かない区分は棒にせず、下に「3杯未満で出していない区分：昼（11〜17時） 2杯」と出る
5. 「時間帯ごとによく選んだ焙煎度」に、「朝 中深煎りが74%（74杯）」のように出る
6. いちばん下の「季節ごとの好み」に、季節ごと（春3〜5月・夏6〜8月・秋9〜11月・冬12〜2月）の、★のいちばん高い焙煎度と、ホットとアイスの★が出る（その季節の★のある杯が5杯から）
- 「気温」「湿度」「天気」は、天気の付いた杯だけで比べます。まだないときは「天気の地点を決める」を押す（「14. 天気の地点を決める」）
- 気分は、淹れる画面で気分を選んだ杯だけが「目覚め」などに入ります。選ばなかった杯は「選ばなかった」

## カレンダーとカフェイン
1. 「カレンダーとカフェイン」を押す
2. 月のカレンダーに、淹れた日の杯数が出る。色が濃いほど杯数が多い。今日は枠で囲まれている
3. 「‹ 前」「次 ›」で前後の月に移る
4. 下の「カフェイン（直近30日）」に、今日の量・飲んだ日の平均・いちばん多い日と、日ごとの棒が出る
- カフェインは、抽出液の量と比率からの目安です（比率1:15で100mLあたり60mg）

## 注意
- 分析の数字は、記録が増えると変わります。件数と信頼度も一緒に見てください
- 分析の画面のコストは、「豆と在庫」の「コスト」と同じ画面です（「6. コストと店の台帳」）
