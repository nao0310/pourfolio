# 14. 天気の地点を決める

地点を決めると、淹れた杯にその時刻の気温・湿度・天気が自動で付き、暑い日にはトップ画面にアイスのすすめが出ます。付いた天気は「10. 分析を見る」の「生活との関係」で使います。

## 地点を決める
1. 画面の下のタブ「その他」を押す
2. 「天気の地点」を押す
3. 「地点」の欄の「都道府県（県庁所在地の天気）」を押し、住んでいる都道府県を選ぶ
4. 「保存する」を押す
5. ボタンの下に「地点を『東京都（新宿）』にしました」と出れば完了
6. 下の「いまの様子」に、いまの天気（例：「12.1℃・湿度61%・晴れ」）、今日の最高気温、受け取った時刻、「天気の付いた杯 13杯／15杯」が出る

## もっと細かい地点にする（したいときだけ）
1. 「都道府県」でいちばん下の「緯度・経度を手で入れる」を選ぶ
2. 下に出る「地点の名前」に、自分で分かる名前（例：家）を入れる
3. 「緯度」「経度」に数を入れる（例：35.68 と 139.76。地図アプリで場所を長く押すと出ます）
4. 「保存する」を押す。「地点を『家』にしました」と出れば完了

## 暑い日の線を変える
1. 「暑い日の線」の欄で、「−」「＋」を押して温度を決める（初めは28℃）
2. 「線を保存する」を押す
3. 「最高気温28℃以上の日にアイスをすすめます」と出れば完了

## 天気を使うのをやめる
1. 「都道府県」でいちばん上の「決めない（天気を使わない）」を選ぶ
2. 「保存する」を押す。「地点を消しました。天気は問い合わせません」と出れば完了（付いた天気は杯に残ります）

## コツ
- 天気は淹れるたびではなく、トップ画面か「天気の地点」の画面を開いたときに、1時間に1回まとめて受け取ります。通信がない日に淹れた杯も、次に通信できるときにトップ画面を開くと付きます
- 今すぐ受け取りたいときは、「いまの様子」の「天気を取り直す」を押す
- 天気は過去92日までさかのぼって付きます。地点を決める前の杯でも、92日以内なら付きます

## 注意
- 外に送るのは地点の緯度・経度だけです。位置情報の許可は使いません。天気は Open-Meteo（無料・登録なし）から受け取ります
- 通信できないときや受け取れなかったときは、「いまの様子」の下に「天気を受け取れませんでした」と出ます。ほかの機能はそのまま使えます
- 地点と暑い日の線は書き出しファイルに入ります。受け取った天気の控えは、その端末だけに置きます
