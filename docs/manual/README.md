## 書き方のルール
- 1ページ＝1つの作業。並びは、目的（1文）→ 手順（番号付き、1手順1操作）→ コツ → 注意
- 画面写真は使わない。ボタン名は「」で囲み、押す場所（画面の下、右上など）と押したあとに出る表示を文章で書く
- iPhoneでの操作を基準に書く
