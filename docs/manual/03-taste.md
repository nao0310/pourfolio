# 3. 評価する

淹れた1杯の味を記録します。★と一言だけなら数秒、ちょうど良さまで入れても30秒ほどで終わります。ちょうど良さは、次のステップで作る「次の1杯の直し方」の手がかりになります。

## 淹れたあとに評価する
1. 抽出の「実績の確認」で、画面下の「保存する」を押す
2. 「味の評価」の画面に変わる。上に「抽出を保存しました」と豆の残りの量が出る
3. 「総合」で、☆を左から数えて好きな数だけのところを押す（4なら左から4つ目）。押したところまで★になり、右に「4 / 5」と出る
4. 「一言」で、当てはまる言葉（「酸っぱい」「苦い」「薄い」「濃い」「渋い」「甘い」「好き」）を押す。いくつ押してもよい。押した言葉は色が付く
5. 「ちょうど良さ」で、項目ごとに5つのボタンから1つを押す。自分にとって弱すぎるか強すぎるかで選ぶ
   - 濃さ：「薄すぎ」「やや薄い」「ちょうど」「やや濃い」「濃すぎ」
   - 酸味・苦味・甘さ・渋み：「弱すぎ」「やや弱い」「ちょうど」「やや強い」「強すぎ」
   - ボディ：「軽すぎ」「やや軽い」「ちょうど」「やや重い」「重すぎ」
   - 押したボタンに色が付き、項目名の右に選んだ言葉が出る
6. 気づいたことがあれば「メモ」に書く
7. 画面下の「評価を保存する」を押す
8. 「評価を保存しました」と、評価のまとめ（例：「★4　酸っぱい　酸味 やや強い」）が出れば完了

## あとで評価する
1. 「味の評価」の画面の下にある「あとで評価する」を押す。トップ画面に戻る
2. 飲み終えたら、トップ画面を開く。いちばん上に「まだ評価していない1杯」が出ている
3. 「評価する」を押す。「味の評価」の画面に変わるので、上の手順3から進める

## 評価を直す
- 保存したすぐあとなら、「評価を保存しました」の画面の「評価を直す」を押す。入れた内容が残った状態で「味の評価」の画面に戻る
- 直したら、画面下の「評価を直して保存する」を押す。評価は1杯につき1つのままで、前の評価が新しい内容に置き換わる

## コツ
- ほとんどの項目がちょうど良いときは、「ちょうど良さ」の右上の「全部ちょうど」を押してから、ずれている項目だけ押し直すと早い
- 分からない項目は押さなくてよい。押さなかった項目は「未回答」として残り、「ちょうど」とは別に扱われる
- 間違えて押したボタンや★は、もう一度押すと消える（未回答に戻る）
- 一言や「ちょうど良さ」を入れなくても、★だけで保存できる

## 注意
- ★・一言・ちょうど良さ・メモのどれも入れずに保存すると、「★・一言・ちょうど良さのどれか1つを入れてください」と出て保存できない
- トップ画面の「まだ評価していない1杯」に出るのは、淹れてから24時間以内で、まだ評価していないいちばん新しい1杯だけ
- 次の1杯の直し方（提案）は、まだ出ない（ステップ1-6で作る）
