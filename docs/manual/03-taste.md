# 3. 評価する

淹れた1杯の味を記録します。★と一言だけなら数秒、ちょうど良さまで入れても30秒ほどで終わります。ちょうど良さは、「次の1杯の直し方」（4. 提案を読む）の手がかりになります。時間があるときは、香味・強さと好み・冷めてからの味・写真・TDSも残せます。

## 淹れたあとに評価する
1. 抽出の「実績の確認」で、画面下の「保存する」を押す
2. 「味の評価」の画面に変わる。上に「抽出を保存しました」と豆の残りの量が出る
3. 題名の下の3つのボタン（「熱いうち」「温かいうち」「冷めてから」）は、「温かいうち」に色が付いていることを確かめる。淹れてすぐの評価は「温かいうち」で入れる
4. 「総合」で、☆を左から数えて好きな数だけのところを押す（4なら左から4つ目）。押したところまで★になり、右に「4 / 5」と出る
5. 「一言」で、当てはまる言葉（「酸っぱい」「苦い」「薄い」「濃い」「渋い」「甘い」「好き」）を押す。いくつ押してもよい。押した言葉は色が付く
6. 「ちょうど良さ」で、項目ごとに5つのボタンから1つを押す。自分にとって弱すぎるか強すぎるかで選ぶ
   - 濃さ：「薄すぎ」「やや薄い」「ちょうど」「やや濃い」「濃すぎ」
   - 酸味・苦味・甘さ・渋み：「弱すぎ」「やや弱い」「ちょうど」「やや強い」「強すぎ」
   - ボディ：「軽すぎ」「やや軽い」「ちょうど」「やや重い」「重すぎ」
   - 押したボタンに色が付き、項目名の右に選んだ言葉が出る
7. 気づいたことがあれば「メモ」に書く。キーボードのマイク（🎤）を押すと、話して入力できる
8. 画面下の「評価を保存する」を押す
9. 「評価を保存しました」と、評価のまとめ（例：「★4　酸っぱい　酸味 やや強い」）が出れば完了。その下に「次の1杯」の提案が出る（「4. 提案を読む」）

## 香味と雑味を選ぶ（したいときだけ）
1. 「味の評価」の画面の「香味」で、感じた香りや味のなかま（「フローラル」「フルーティ」「ナッツ・ココア」など9つ）を押す
2. 下に、そのなかまの言葉（フルーティなら「ベリー」「柑橘」「レモン」など）が出る。近い言葉を押す。いくつ押してもよい
3. 細かい言葉が分からないときは、言葉の並びの最初にある、なかまの名前（例：「フルーティ」）を押す
4. 選んだ言葉は「香味」のすぐ下に「柑橘 ×」のように並ぶ。なかまのボタンの右上には、選んだ数が出る
5. 外すときは、並んだ「柑橘 ×」を押す
6. えぐみや紙のにおいなど気になる味があれば、「雑味」の「えぐい」「紙っぽい」「焦げ」「古い（酸化）」「水っぽい」を押す
7. 画面下の「評価を保存する」を押す。評価のまとめに「柑橘・ジャスミン」「雑味 えぐい」のように出る

## 強さと好みを分けて評価する（したいときだけ）
酸味が「強い」ことと、それが「好き」かどうかは別のことです。ここでは7つの項目（香り（粉）・香り（液）・風味・余韻・酸味・甘さ・口当たり）ごとに、両方を分けて記録します。
1. 「味の評価」の画面の「詳しく評価する（強さと好み）」を押す。7つの項目が開く
2. 「強さ」は、どれだけ感じるかを0〜15で入れる。横棒（スライダー）を指で動かすか、「−」「＋」を押す。右に数字が出る（0＝感じない、15＝とても強い）
3. 「好み」は、どれだけ好きかを1〜9のボタンから1つ押す（1＝とても嫌い、5＝どちらでもない、9＝とても好き）
4. 項目名の右に「強さ 12・好み 3（やや嫌い）」のように出る。分からない項目は入れなくてよい
5. 画面下の「評価を保存する」を押す。開き直すと、入れた項目の数が「詳しく評価する」の右に「2項目」のように出る

## 冷めてからの味を評価する
冷めると酸味や甘さ、雑味がはっきりします。淹れてすぐの評価とは別に、冷めてからの評価を1つ残せます。
1. 「評価を保存しました」の画面に「○時○分ごろ（落ち切って15分後）に、冷めた味も評価できます」と出る
2. そのころトップ画面を開くと、「冷めた味を評価しませんか」と出ている。「冷めた味を評価する」を押す
3. 「味の評価（冷めてから）」の画面に変わり、上の3つのボタンの「冷めてから」に色が付いている
4. 上の「淹れたあとに評価する」の手順4から同じように入れて、「評価を保存する」を押す
5. 「冷めてからの評価を保存しました」と出て、「温度帯ごとの評価」に「温かいうち」と「冷めてから」のまとめが並べば完了

淹れたての熱い味も残したいときは、「味の評価」の画面の上で「熱いうち」を押してから入れます。

## 写真を残す（したいときだけ）
1. 「味の評価」の画面をいちばん下まで動かす。「写真」に「粉」「粉の層」「抽出液」の3つの枠がある
2. 撮りたい枠の「撮る・選ぶ」を押す
3. 出てきたメニューで「写真を撮る」（その場で撮る）か「写真ライブラリ」（撮ってある写真から選ぶ）を押す
4. 撮るか選ぶと、「写真を小さくしています…」のあと「抽出液の写真を保存しました」と出て、枠に写真が出れば完了。評価の「保存する」を押さなくても、写真はもう保存されている
5. 写真を押すと画面いっぱいに大きく出る。もう一度押すと戻る

## TDS（屈折計）を入れる（測ったときだけ）
1. 「味の評価」の画面をいちばん下まで動かす。「写真」の下に「TDS（屈折計）」がある
2. 冷ましてから測った値（例：1.38）を入れ、右の「保存」を押す
3. 「TDSを保存しました」と出て、その下に「抽出収率 19.8%（抽出液 209g・見積もり）」のように出れば完了。評価の「保存する」を押さなくても、TDSはもう保存されている
- 抽出液を量っていない杯は、「湯量−2×粉量」で抽出液を見積もります。同じドリッパーで抽出液を量った杯が2杯以上あると、その値から見積もり直します
- 消すときは、欄を空にして「保存」を押す（「TDSを消しました」と出ます）
- 入れたTDSは、分析の「抽出チャート」に点として出ます（「10. 分析を見る」）

## 1枚の画像にする（したいときだけ）
- 「味の評価」の画面のいちばん下の「1枚の画像にする」で、豆・条件・★・注湯の流れを1枚の画像にできる。手順は「13. 共有・QR・印刷」

## あとで評価する
1. 「味の評価」の画面の下にある「あとで評価する」を押す。トップ画面に戻る
2. 飲み終えたら、トップ画面を開く。いちばん上に「まだ評価していない1杯」が出ている
3. 「評価する」を押す。「味の評価」の画面に変わるので、上の手順4から進める

## 評価を直す
- 保存したすぐあとなら、「評価を保存しました」の画面の「評価を直す」を押す。入れた内容が残った状態で「味の評価」の画面に戻る
- 直したら、画面下の「評価を直して保存する」を押す。評価は1杯・1つの温度帯につき1つのままで、前の評価が新しい内容に置き換わる
- 写真を撮り直すときは、枠の「撮り直す」を押す。前の写真は消えて、新しい写真に置き換わる。写真だけ消すときは「消す」を押し、「元に戻せません」と出たら「OK」を押す

## コツ
- ほとんどの項目がちょうど良いときは、「ちょうど良さ」の右上の「全部ちょうど」を押してから、ずれている項目だけ押し直すと早い
- 分からない項目は押さなくてよい。押さなかった項目は「未回答」として残り、「ちょうど」とは別に扱われる
- 間違えて押したボタンや★は、もう一度押すと消える（未回答に戻る）。強さと好みは、項目名の右の「消す」で未回答に戻る
- 一言や「ちょうど良さ」を入れなくても、★だけで保存できる
- 毎日の1杯は★・一言・ちょうど良さだけにして、新しい豆や気に入った豆のときに香味・強さと好み・冷めてからの評価を足すと続けやすい

## 注意
- ★・一言・ちょうど良さ・香味・雑味・強さと好み・メモのどれも入れずに保存すると、「★・一言・ちょうど良さなど、どれか1つを入れてください」と出て保存できない
- 「次の1杯」の提案は、「温かいうち」の評価からだけ出る。「熱いうち」「冷めてから」の評価では提案は変わらない
- 温度帯のボタンを押すと、保存していない入力は消える（「保存していない入力は消えます」と出たら、残したいときは「キャンセル」を押して先に保存する）
- トップ画面の「まだ評価していない1杯」に出るのは、淹れてから24時間以内で、まだ評価していないいちばん新しい1杯だけ。「冷めた味を評価しませんか」は、落ち切ってから15分〜3時間の間だけ出る
- 雑味は記録だけで、次の1杯の提案には使わない
- 写真はこの端末の中にだけ保存する。写真が多いと書き出しのファイルが大きくなる（「7. 書き出し・復元」）
