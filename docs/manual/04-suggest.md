# 4. 提案を読む（次の1杯の直し方）

味の評価から、次の1杯で変えることを1つだけ、どれだけ変えるかと理由を添えて出します。提案どおりに淹れて評価を重ねると、自分の豆とグラインダーに合った味に近づきます。

## 評価のあとで提案を見る
1. 「味の評価」の画面で、「ちょうど良さ」の「濃さ」「酸味」「苦味」「渋み」を押す（一言の「薄い」「濃い」「酸っぱい」「苦い」「渋い」だけでもよい）
2. 画面下の「評価を保存する」を押す
3. 「評価を保存しました」の下に、茶色の枠の「次の1杯」が出る
   - 枠の上の小さな文字：今の1杯の状態（例：「酸っぱい・余韻が短い」）
   - 太字：次に変えること（例：「挽き目を1目盛り細かく：挽き目 24 → 23」）
   - その下の小さな文字：別の手（例：「または湯温を2℃上げる」）や、次の次に直すこと
4. 「根拠」の4つを読む
   - あなたの入力：判断に使った評価（例：「酸味 やや強い」）
   - 理論：濃さと抽出の3×3のどのマスか
   - あなたの実績：同じ直し方をしたとき、次の杯で味がどう動いたか（例：「この豆で挽き目を細かくした3回中2回で、次の杯の酸味が下がった」）
   - 確信度：「高い」「ふつう」「低い」と、その理由

## 提案どおりに淹れる
1. 「次の1杯」の枠にある「この提案で淹れる」を押す（今のままでよいときは「同じ計画で淹れる」）
2. 抽出の画面に変わる。上に「提案を入れた計画です」と出て、「計画」の変えた項目（例：「挽き目（変更）」）が茶色の枠で囲まれている
3. あとはいつもどおり「スタート」を押して淹れ、評価する
- レシピそのものは変わらない。この1杯の計画だけが変わる
- 評価を保存すると、提案どおりに淹れた結果が「あなたの実績」に貯まっていく

## あとで提案を使う
- いちばん早いのは、トップ画面の「今日の1杯」の「提案を入れて淹れる」を押すこと（前回の豆にまだ使っていない提案があるときに出る）

レシピから選ぶときは、次の手順で使えます。
1. 画面の下のタブ「淹れる」から、いつものレシピを選ぶ（または、トップ画面の「今日の1杯」の「前回と同じで淹れる」を押す）
2. 「豆」で、前回評価した豆を選ぶ
3. その豆にまだ使っていない提案があると、上に「この豆の前回の提案」が出る
4. 「この提案を入れる」を押すと、提案を入れた計画に変わる。押さずに「スタート」を押せば、提案を使わずに淹れられる

## コツ
- 1杯で変えるのは1つだけ。いくつも変えると、どれが効いたか分からなくなる
- 濃さと抽出の両方がずれているとき（例：「薄くて酸っぱい」）は、先に濃さを直す提案が出る。濃さが直ったら、次の杯で抽出を直す提案が出る
- 酸味と苦味・渋みの両方が強いときは、どちらに直すか決められないので「同じ条件でもう1杯」と出る。もう一度淹れて確かめる
- 挽き目は「数字が小さいほど細かい」として計算する。1目盛りの大きさは、器具の登録の「目盛りの刻み」を使う（入れていなければ1）

## 注意
- ★とメモだけ、または「甘い」「好き」だけでは提案は出ない。「ちょうど良さの……を入れると、次の1杯の直し方が出ます」と案内が出る
- 挽き目を数字で記録していないと、目盛りの数字は出ない。「目盛りは手で合わせてください」と出るので、自分で1目盛り動かす。ボタンは「提案を入れて淹れる（目盛りは手で）」になる。「酸っぱい・余韻が短い」のときは、代わりに「湯温を2℃上げて淹れる（92℃ → 94℃）」のボタンも出て、押すと湯温だけを上げた計画で抽出の画面が開く
- 提案を使わずに同じ豆で淹れると、その提案は「使わなかった」として記録され、出なくなる
- 評価を直すと提案も作り直される。ただし、提案を使って次の1杯をもう淹れたあとは変わらない
