# 11. 今日の一杯を選ぶ（おすすめ・気分・量とアイス・新しい豆の最初のレシピ）

手元の豆から今日淹れる豆を理由つきで選び、気分・量・アイスに合わせて淹れ方を直します。新しい豆には、最初のレシピを出します。

## トップ画面のおすすめで淹れる
1. トップ画面の「今日の1杯」を見る
2. 「おすすめ：（豆の名前）」の下に、理由が2〜3行出る（例：「この豆の★平均 4.3（6杯）」「飲み頃です（焙煎から6日）」）
3. 「おすすめで淹れる」を押す
4. 抽出の画面に変わり、上に「★がいちばん高かった杯：（レシピの名前）」（まだ淹れていない豆なら「（豆の名前）の最初のレシピ」）と出れば完了
5. あとはいつもどおり「スタート」を押して淹れ、評価する

- 前回の豆にまだ使っていない提案があるときは、「提案を入れて淹れる」がいちばん上のボタンになり、その下に「おすすめで淹れる」が出る
- 朝（5〜10時）は気分「目覚め」、夜（18時以降）は「くつろぎ」で選ぶ。そのときは「今の時間なので気分「目覚め」で選びました」と出る

## ほかの候補と気分を見る
1. トップ画面の「今日の1杯」のいちばん下の「ほかの候補・気分を変える」を押す
2. 「今日の一杯」の画面に変わり、1〜3位の豆が理由と一緒に出る
3. 「気分」の「なし」「目覚め」「くつろぎ」「食後」「来客」のどれかを押す
4. 順位と理由が変わる。ボタンの下に「狙い：明るい酸味・やや濃いめ」のような説明が出る
5. 淹れたい豆の「これで淹れる」を押す

気分ごとの淹れ方の直し方：
- 目覚め（明るい酸味・やや濃いめ）：比率を0.5濃く。4:6メソッドなら味を「明るめ」、濃さを「濃いめ」
- くつろぎ（甘さ重視・やや薄め）：比率を0.5薄く。4:6メソッドなら味を「甘め」
- 食後（ボディ重視）：比率を0.5濃く。4:6メソッドなら濃さを「濃いめ」
- 来客（失敗しにくい定番）：数字は変えず、2杯ぶんにする。★4以上が続いている豆を上にする

## カフェインを控える時刻を決める
1. 「今日の一杯」の画面のいちばん下の「カフェイン」を見る。「今日のカフェインは約○mg（1日の目安 400mg、朝5時から）」と出る
2. 「この時刻からカフェインを控える」を押し、時刻（例：15:00）を選ぶ
3. 「15:00から控えるようにしました」と出れば完了。トップ画面の「カフェイン」にも、控える時刻までの残り時間が出る
4. やめるときは「使わない」を押す

- 控える時刻から朝5時までと、その日のカフェインが400mgを超えたときは、「カフェインレス」の印の付いた豆が上に来て、ほかの豆は「少なめ（0.7杯）」で淹れるようにする
- 豆に「カフェインレス」の印を付けるには、豆の編集画面で「焙煎度」の下の「カフェインレス（デカフェ）」を押して保存する

## 量・アイス・気分を選んで淹れる
どのレシピから淹れるときも、抽出の画面で量・アイス・気分を変えられます。
1. 抽出の画面の「量と気分」を見る
2. 「量」で「少なめ」「1杯」「2杯」「3杯」「4杯」のどれかを押す。「計画」の粉量・湯量と「注湯の予定」が、その量に変わる
3. 冷たくしたいときは「アイス（急冷）」を押す。「計画」に「お湯」と「氷」が分かれて出る（湯量の6割をお湯、4割を氷）
4. 「気分」を押すと、比率や4:6の配分が変わる
5. 「計画」の下に、何をどう変えたか（例：「アイス：お湯 180g を注ぎ、サーバーに氷 120g を入れておきます」）が出る
6. 「スタート」を押して淹れる

- アイスのときは、注ぐ前にサーバーに氷を入れておく。挽き目は1目盛り細かくすると、薄まっても味がぼやけにくい
- アイスで淹れた杯を「前回と同じで淹れる」で開くと、最初から「アイス」が選ばれている。外すと元の湯量に戻る
- 量・アイス・気分は、抽出の記録とCSVの「気分」「杯数」「氷g」の列に残る

## 新しい豆の最初のレシピ
1. 豆を登録する（「1. 豆を登録する」）
2. 豆の画面のいちばん上に「この豆の最初のレシピ」が出る。右上の札は、どこから決めたか（「似た豆から」「自分の初期値」「焙煎度の叩き台」）
3. 太字の「15g・1:15.5・93℃・挽き目 24（中細挽き）」と、その下の理由を読む
4. 「この計画で淹れる」を押す
5. 抽出の画面に変わり、「この豆の最初のレシピ」の枠に理由が出れば完了

決め方：
- 似た豆（焙煎度が同じか1段違いで、精製・産地・品種が近い豆）で★4以上の杯が2杯以上あれば、その粉量・比率・湯温・挽き目の真ん中の値
- 似た豆がなくても、同じ焙煎度の区分（浅煎り・中煎りなど）で★を付けた杯が5杯以上（うち★4以上が2杯以上）あれば、その真ん中の値（自分の初期値）
- どちらもなければ、焙煎度の叩き台（ライト〜ミディアム：93℃・1:15.5・中細挽き、ハイ〜シティ：90℃・1:15・中挽き、フルシティ〜イタリアン：87℃・1:14.5・中挽き〜やや粗め）

## コツ
- 注ぎ方は、いちばん使っているレシピ（お気に入りがあればそれ）を土台にする。4:6メソッドのレシピなら、比率に合わせて注湯を作り直す
- グラインダーに目盛り表があれば、「中細挽き」のような言葉を目盛りの数字にして出す。別のミルで淹れた杯の挽き目も換算して使う

## 注意
- おすすめは、1杯ぶん以上残っている豆から選ぶ。飲み切り・入荷待ちの豆は出ない
- 量やアイスを変えた杯では、タイマーの「ベスト比」は出ない（ペースが変わるため）
- アイスの杯は、抽出チャートと「条件と評価」には入らない（氷で薄まり、比べられないため）。★は好みの集計に入る
- 「最初のレシピ」は、まだ淹れていない豆にだけ出る。1杯淹れると消える
