# 17. お店で飲んだ1杯を記録する

喫茶店やカフェで飲んだコーヒーを、手で淹れた記録とは分けて残します。分析・提案・カフェインの数には入りません。

## 記録する
1. 画面の下のタブ「その他」を押す
2. 「お店で飲んだ1杯」を押す
3. 「店の名前（必須）」に店の名前を入れる（前に入れた店は、欄を押すと候補に出る）
4. 「飲んだ日時（必須）」は開いた時刻が入っている。あとから記録するときは押して直す
5. あれば「飲み物の名前」「淹れ方」（ハンドドリップ／エスプレッソ／ラテなど／その他）「ホット・アイス」「豆（産地・銘柄）」「焙煎度」「値段」「★」「メモ」を入れる
6. 「記録する」を押す
7. 画面の下に「「○○」の1杯を記録しました」と出て、下の「これまでの記録」のいちばん上に並ぶ

## 直す・削除する
1. 「これまでの記録」で、直したい記録の「編集する」を押す
2. 上の欄に中身が入り、題が「「○○」の記録を直す」になる。直して「保存する」を押す（やめるときは「やめる」）
3. 削除するときは「削除する」を押し、確認の箱で「削除する」を押す

## 探す
1. 「これまでの記録」の「さがす」の欄に、店・飲み物・豆・メモの言葉を入れる
2. 入れた言葉を含む記録だけが並ぶ（空白で区切ると、すべてを含むものだけ）

## コツ
- 書かなくてよい欄は空のままで記録できます。淹れ方・ホット・アイスは、選んだものをもう一度押すと外せます。★も同じ★をもう一度押すと外せます

## 注意
- お店の1杯は、分析・提案・カフェイン・年間まとめ・今日の1杯には入りません
- 写真は付けられません
- 書き出し（「その他」→「データ（書き出し・保存）」）には入るので、ほかの記録と同じように定期的に書き出してください
