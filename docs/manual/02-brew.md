# 2. 器具とレシピを登録して淹れる

使う器具とレシピを登録しておくと、次からはレシピを選んで1タップで淹れ始められます。淹れるときはタイマーが注湯の時刻と量を知らせ、終わったら実際の量と時間を記録します。

## 器具を登録する
1. トップ画面の下の「器具」を押す
2. 画面下の「＋ 器具を登録」を押す
3. 「種類」で「ドリッパー」「フィルター」「グラインダー」「ケトル」「スケール」のどれかを押す
4. 「名前」に器具の名前を入れる。ドリッパーは、名前の下の候補（「V60」など）を押しても入れられる
5. 毎回使う器具なら「いつも使う」にチェックを入れる
6. 種類ごとの詳細を入れる（入れなくても登録できます）
   - ドリッパー：「形状」「穴の数」「素材」
   - フィルター：「素材」。紙を選ぶと「漂白」も選べる
   - グラインダー：「刃の種類」「目盛りの刻み」「ゼロ点」
7. 画面下の「登録する」を押す
8. 器具の一覧に戻り、種類の見出しの下に名前が出れば完了。「いつも使う」の器具には「いつも使う」の札が付く

## レシピを作る（4:6メソッドの雛形）
1. トップ画面の下の「淹れる（レシピ）」を押す
2. 画面下の「＋ レシピを作る」を押す
3. 「雛形」で「4:6メソッド」が選ばれていることを確かめる
4. 「味」で「甘め」「標準」「明るめ」のどれかを押す。下の「注湯」の1投目と2投目の量が変わる
5. 「濃さ」で「軽め」「標準」「濃いめ」のどれかを押す。後半の注湯の回数が変わる
6. 「粉量」を「−」「＋」で合わせる（0.5gずつ動く）。湯量と注湯が自動で計算し直される
7. 必要なら「比率」「湯量」「湯温」も「−」「＋」で直す
8. 「グラインダー」を選び、「挽き目（目盛り）」に今の目盛りを入れる
9. 「名前」を確かめる（雛形の名前が自動で入っている。自分の名前に変えてもよい）
10. 画面下の「保存する」を押す
11. 「淹れる」の一覧に戻り、作ったレシピが出れば完了

## レシピを作る（基本形・自分で決める）
- 「雛形」で「基本形」を押すと、粉量の2倍のお湯で蒸らし、残りを2回か3回に分けて注ぐレシピになる。回数は「2回」「3回」で選ぶ
- 「自分で」を押すと、注湯を自由に決められる。各投の「時間」（例：0:45）と「累計(g)」（スケールに表示される合計）を入れる
- 注湯を足すときは「＋ 注湯を足す」、消すときはその投の右の「×」を押す

## 注ぐ秒数と流速を決める
各投の下に「注ぐ秒数」があります。その投を何秒で注ぎ終えるかの目安で、タイマーの「注ぐ」と「待つ」の切り替わりに使います。
1. 「注湯」の上の「目安の流速」を「−」「＋」で合わせる（初めは10g/秒）。手で直していない投の「注ぐ秒数」が「注ぐ量÷流速」で計算し直される
2. 1つの投だけ変えたいときは、その投の「注ぐ秒数」を「−」「＋」で直す。下に「流速 ○g/秒」が出る（自動で計算した投には「（自動）」と付く）
3. 手で直した投は、流速を変えてもそのまま残る
- 注ぐ秒数が次の注湯の時刻を越えると保存できない（「○投目は次の注湯までに注ぎ終わりません」と出る）。秒数を短くするか、次の投の「時間」を遅くする
- 前に作ったレシピは、注ぐ量÷10g/秒で計算した秒数が入っている

## レシピから淹れる
1. トップ画面の下の「淹れる（レシピ）」を押す
2. 淹れたいレシピの「淹れる」を押す
3. 抽出の画面に変わり、粉量・湯量・湯温などの「計画」と「注湯の予定」が出れば完了
4. 「豆」で今日淹れる豆を選ぶ（前回の豆が最初から選ばれている）

前に淹れたことがあるときは、「淹れる」の一覧のいちばん上に「前回と同じで淹れる」が出ます。これを押すと、前回と同じ計画で抽出の画面に進みます。

## 準備を確かめる（抽出前チェック）
1. 抽出の画面を下に動かすと、「準備チェック」に4つの項目が並んでいる
   - 「湯温 92℃」：ケトルの湯が計画の温度になっている
   - 「リンス」：ペーパーフィルターを湯で流した
   - 「予熱」：ドリッパーとサーバーを温めた
   - 「スケールの0点」：粉を入れてから0gに合わせた
2. 済んだものを押すと、左の四角に印が付く。押さなくてもスタートできる
3. 印を付けた項目は、抽出の記録に残る（CSVの「抽出前チェック」の列）

## タイマーで淹れる
1. 抽出の画面で、「豆」が今日淹れる豆になっていることを確かめる
2. 画面下の「スタート」を押す。「ピッ」と鳴り、「蒸らし、○○グラムまで」と読み上げる
3. 画面の上半分に、経過時間・茶色の「注ぐ」の札・「累計 ○○g」（スケールの合計をこの値まで注ぐ）・「注ぎ終わりまで あと○秒」が大きく出る
4. 注ぎ終えたら、画面の下半分（「注湯完了」と書かれた広い部分）のどこかを押す。押さなくても、注ぐ秒数が過ぎると短い音が1回鳴り「待つ」に変わる（このときは押すと注ぎ終えた時刻が記録される）
5. 「待つ」の間は、青い「待つ」の札・「次：2投目」・次の「累計 ○○g」・「次の注湯まで あと○秒」が出る。下半分は「待っています」になり、押しても何も起きない。3秒前から短い音が3回鳴り、時刻になると長い音と「2投目、○○グラムまで」の読み上げがあって「注ぐ」に変わる
6. 同じように、注ぎ終えるたびに下半分を押す。最後の投は「注ぎ終えた」と出る（最後の投は押すまで落ち切り待ちにならない）
7. 全部注ぎ終えると、下半分が緑になり「落ち切った」と出る。上には「目標まで あと○秒」（過ぎると「目標を○秒 超過」）が出る
8. ドリッパーからお湯が落ち切ったら、下半分の「落ち切った」を押す
9. 「実績の確認」の画面に変わる

## 実績を確かめて保存する
1. 「粉量」「湯量」「湯温」には計画の値が入っている。実際と違うときは「−」「＋」で直す
2. 挽き目を変えて淹れたときは「挽き目」を直す
3. 「総時間」にはタイマーの時間が入っている。必要なら「3:30」のように直す
4. 抽出液を量ったときだけ「抽出液の重さ」を入れる。気づいたことは「メモ」に書く（キーボードのマイク🎤で話して入力できる）
5. 「計画との差」に「湯量 +2g」「時間 +15秒」のように差が出る。計画どおりなら「計画どおりです」と出る
6. 画面下の「保存する」を押す
7. 「味の評価」の画面に変わり、上に「抽出を保存しました」と豆の残りの量（「○○の残り ○○g（あと○杯）」）が出れば完了。豆の残量は、入れた粉量の分だけ減っている。続けて味を評価する（「3. 評価する」）。粉や抽出液の写真は、その画面のいちばん下の「写真」で残せる

タイマーを使わずに淹れたときは、抽出の画面の「タイマーを使わずに記録する」を押すと、すぐに「実績の確認」の画面になります。「総時間」を入れてから保存します。

## コツ
- よく使うレシピは、名前の右の「☆」を押すと「★」になり、一覧の上に出るようになる
- グラインダーの「目盛りの刻み」を入れておくと、レシピの挽き目を「−」「＋」でその幅ずつ動かせる
- レシピを直すときは、一覧の「編集」を押す。直すと抽出の画面に出る「版」の番号が1つ上がる。これまでの記録は変わらない

## 注意
- 注湯完了を押し忘れても、次の注湯の時刻になると自動で次の投に進む。押さなかった投は、実績の確認の「注湯の実績」で「—」になる
- 抽出の途中で別のアプリを開いたり、アプリを閉じたりしても、タイマーは止まらない。開き直すと続きから進む。トップ画面に「途中の抽出があります」と出たら「続きに戻る」を押す
- やめるときは、タイマーの左上の「やめる」を押す（「この抽出をやめますか？」と出るので「OK」を押す）。記録は残らない
- 読み上げが要らないときは、タイマーの右上の「読み上げ オン」を押して「読み上げ オフ」にする。次からもオフのまま
- 抽出の間は画面が消えないようにしている。消えてしまうiPhone（iOS 18.4より前）では、タイマーに「自動ロックを長くしてください」と出るので、iPhoneの「設定」→「画面表示と明るさ」→「自動ロック」を長くする
- iPhoneがマナーモード（消音）のときは、音が鳴らないことがある。音が聞こえないときは、マナーモードを外して音量を上げる
- 注湯を手で直すと、雛形とのつながりが外れる（「注湯を手で直したので、雛形との連動を外しました」と出ます）。雛形に戻すときは「雛形」をもう一度押す。注湯は作り直される
- 最後の注湯の累計が湯量と合わないと保存できない。「湯量に合わせる」を押すと自動で合わせられる
- レシピの作成中に器具を登録しに行くと、入力中の内容は消える。先に器具を登録しておく
