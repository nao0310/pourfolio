# 1. 豆を登録する・残量と飲み頃を見る

届いた豆を登録すると、残りの量・あと何杯・飲み頃が見えるようになります。

## 豆を登録する
1. 画面の下のタブ「豆と在庫」を押す
2. 画面下の「＋ 豆を登録する」を押す
3. 「銘柄」に豆の名前を入れる（例：エチオピア イルガチェフェ G1）
4. 「焙煎度」で、注文した焙煎度（ライト〜イタリアン）を押す
5. 「焙煎日」に袋の焙煎日を入れる。袋に書いていなければ発送日を入れる
6. 「表記重量の基準」で、商品ページの重さが生豆時なら「生豆時」、焙煎後なら「焙煎後」を押す
7. 「表記重量」に商品ページの重さ（例：200）を入れる
8. 下に「在庫に入る量：約164g」のように表示されることを確かめる
9. 豆を量ったときは「実重量」に量った重さを入れる（入れなくても登録できます）
10. 画面下の「登録する」を押す
11. 豆の詳細画面に変わり、「残り」に重さと「あと○杯」が出れば完了
12. いちばん上に「この豆の最初のレシピ」が出る。「この計画で淹れる」を押すと、その数字で淹れられる（「11. 今日の一杯を選ぶ」）

産地・品種・精製・注文日・商品ページのURLなどは、「産地・品種・日付などの詳細」を押すと入れられます。カフェインレスの豆は、「焙煎度」の下の「カフェインレス（デカフェ）」を押しておくと、夜のおすすめで上に来ます。

## 商品ページの文章から入れる
珈琲問屋の商品ページの文章を貼り付けると、銘柄・産地・精製・価格などが自動で入ります。
1. Safariで珈琲問屋の豆の商品ページを開き、文章を長押しして「すべてを選択」→「コピー」を押す
2. Pourfolioに戻り、「豆と在庫」→ 画面下の「＋ 豆を登録する」を押す
3. いちばん上の「珈琲問屋の商品ページから入れる」を押す
4. 出てきた枠を長押しして「ペースト」を押す
5. 「読み取る」を押す
6. 「入れた項目：銘柄・産地・精製・…」と出て、下の欄に値が入ったことを確かめる
7. 「焙煎度」を注文した焙煎度に押し直し、「表記重量」を注文したグラム数に直す（価格は重さに合わせて自動で変わります）
8. 画面下の「登録する」を押す

- 商品ページからは、注文で選んだ焙煎度と重さは分かりません。最初は店の標準（ミディアム・生豆時100g）が入るので、必ず直してください
- 注文メールがあるときは、「5. 注文と買い足し」の「注文メールから登録」のほうが早く登録できます

## 1杯淹れた分を減らす
1. 「豆と在庫」で豆を押す
2. 「粉の量」が使った量になっているか確かめる（違うときは直す）
3. 「1杯淹れた」を押す
4. 「15g 減らしました」と出て、「残り」が減れば完了

## 量り直して残量を合わせる
1. 豆の詳細で「量り直す」を押す
2. 袋から出した豆だけの重さを量り、「今の重さ」に入れる（冷凍している袋は量りません）
3. 「合わせる」を押す
4. 「残量を ○g に合わせました」と出れば完了

## おすそ分けする（誰に何gを残す）
1. 豆の詳細で「おすそ分け・廃棄」を押す
2. 「おすそ分け」が選ばれていることを確かめる
3. 「渡した相手」に名前を入れる（例：母）。前に渡したことのある相手は、欄の下のボタンを押すと入る
4. 必要なら「メモ」を入れる（例：豆のまま、挽いて渡した）
5. 「量」に渡した重さを入れ、「減らす」を押す
6. 画面の上に「おすそ分けで ○g 減らしました（母）」と出て、「残り」が減れば完了。「在庫の履歴」に「おすそ分け」と「→ 母」が出る
7. 常温の残りより多い量を入れると、確認の箱が出る。合っていれば「減らす」を押す

## もらった感想を書く
1. 画面の下のタブ「豆と在庫」を押し、上の小さなリンク「おすそ分け」を押す（「その他」の「おすそ分け」からも開ける）
2. 「相手ごと」に、相手ごとの回数・合計の重さ・最後に渡した日・渡した豆が出る
3. 「渡した記録」で、感想を書く記録の「もらった感想を書く」を押す
4. 欄に感想を入れ、「感想を保存する」を押す
5. 上に「感想を保存しました」と出て、記録の下に「感想：…」と出れば完了。直すときは「感想を直す」を押す

## 廃棄で減らす
1. 豆の詳細で「おすそ分け・廃棄」を押す
2. 「廃棄」を押す（相手とメモの欄は消える）
3. 「量」に減らす重さを入れ、「減らす」を押す

## 小分けにして冷凍する
飲み頃のうちに飲みきれない豆は、1杯分ずつ袋に分けて冷凍しておけます。冷凍中は焙煎からの日数を数えません。
1. 「豆と在庫」で豆を押す
2. 「冷凍ストック」の「小分けにして冷凍する」を押す
3. 「1袋の量」を「−」「＋」で合わせる（最初は1杯分の15g）
4. 「袋の数」を「−」「＋」で合わせる。下の「合計 60g（常温の残り 120g）」で量を確かめる
5. 「冷凍した日」が今日になっていることを確かめる
6. 「冷凍する」を押す
7. 「4袋（60g）を冷凍しました。袋に #1〜#4 と書いておきましょう」と出たら、袋にその番号を書いて冷凍庫に入れる
8. 「冷凍ストック」に「#1　15g・11/18に冷凍（焙煎後6日）」のように袋が並び、「残り」の下に「常温 60g＋冷凍 4袋（60g）」と出れば完了

## 冷凍した袋で淹れる
凍ったまま挽いて淹れるときの手順です。
1. いつもどおり「淹れる」から抽出し、「実績の確認」の画面まで進む
2. 「豆」の下の「冷凍の袋を使う：#1　15g・…」に印が付いていることを確かめる（常温の豆が足りないときは、最初から印が付いています）
3. 「保存する」を押す
4. 冷凍庫からいちばん古い袋（表示された番号）が取り出されたことになり、残量が正しく減ります

## 冷凍した袋を取り出す（常温に戻す）
前の晩に冷凍庫から出しておくときなどに使います。
1. 豆の詳細の「冷凍ストック」で、出した袋の番号の「取り出す」を押す
2. 「#1（15g）を取り出し、常温に戻しました」と出れば完了

## 入荷待ちの豆が届いたとき
注文メールから登録した豆は「入荷待ち」になっています。届いたら重さを量って入れます。
1. 「豆と在庫」で「入荷待ち」の札が付いた豆を押す
2. 袋から出した豆だけの重さを量り、「量った重さ」に入れる（下の「目安：生豆時200g → 約166g」が参考になります）
3. 「到着日」が今日になっていることを確かめる
4. 袋に焙煎日が書いてあれば「焙煎日」に入れる（空のときは到着日の前日になります）
5. 「届いた」を押す（画面の下に固定された茶色の「届いた」でもよい。重さが空のときは、押すと重さの欄に移る）
6. 「届いた豆を登録しました」と出て、「飲み頃」と「残り」が表示されれば完了

- 入荷待ちの豆は、届くまで淹れる画面の豆の選択には出ません
- 手元にある豆の画面では、画面の下に「この豆で淹れる」が出る。押すと、その豆で★がいちばん高かった淹れ方（まだなければ最初のレシピ）で淹れる画面が開く。豆の情報を直す「編集」は、画面のいちばん下の「飲み切りにする」「削除」の並びにある

## 飲み切ったとき
1. 豆の詳細の下のほうにある「飲み切りにする」を押す
2. 上に「飲み切りにしました。次の自分への一言を書いておけます」と出て、「次の自分への一言」の欄の所まで画面が動く
3. 次にこの豆を買ったときに伝えたいことを入れて「一言を保存する」を押す（例：焙煎10日目からが良い。挽き目は粗めが合う）。書かなくてもかまいません
4. 一覧から消えます。もう一度見たいときは、一覧の「飲み切りの豆も表示する」にチェックを入れる

## 前回の申し送りを見る（同じ豆・似た豆を開けたとき）
1. 前に飲んだことのある銘柄の豆を、新しく登録する（「豆を登録する」）
2. 豆の画面のいちばん上に「前回の申し送り」が出る。同じ銘柄がなければ、焙煎度・精製・産地の似た豆から出る（「似た豆「○○」から」と理由が出る）
3. 前に書いた「次の自分への一言」、「ベストの条件」（★がいちばん高かった杯の日付・焙煎からの日数・g・比率・℃・挽き目・時間）、飲み頃の山、評価のメモが出る
4. 「この条件で淹れる」を押すと、その条件で、新しい袋の豆を選んだ淹れる画面が開く
5. この袋で3杯淹れると出なくなる。先に消したいときは右上の「×」を押す（この豆ではもう出ない）

## 飲み頃の見方
- 札の色と文字で、今の段階がわかります：「休ませ中」→「飲み頃」→「ピーク後」→「早めに消費」
- 常温の豆がなく、冷凍の袋だけ残っている豆には「冷凍中」の札が付きます（「早めに消費」の知らせは出しません）
- 豆の詳細の帯の黒い線が今日の位置です
- 日数の目安は焙煎度で変わります（例：シティ・フルシティは2〜8日目が飲み頃）
- この豆で淹れた杯があると、「飲み頃」のカードの下の「エイジング日誌」に、この豆で★がいちばん高かった日数（飲み頃の山）が出ます。「日数ごとの★と記録を見る」で詳しく見られます（「10. 分析を見る」）

## コツ
- 生豆時の表記で登録すると、焙煎で減る分（シティなら18%）を見積もって在庫に入れます。届いた豆を量って「実重量」に入れておくと、次からはその実績を使って見積もります
- 残り杯数は1杯15gで計算します。変えたいときは、一覧の下の「1杯の粉の量」を直して「保存する」を押す
- なくなる日の目安は、2週間で2杯以上淹れると表示されます
- 間違えて減らしたときは、「在庫の履歴」の「取り消す」を押し、確認の箱でも「取り消す」を押す
- 「量り直す」「減らす」などの知らせ（「残量を ○○g に合わせました」など）は、画面のいちばん上に4秒ほど出て消えます
- 「残り」と「あと○杯」は、常温と冷凍の袋を合わせた量です
- 間違えて冷凍したときは、「在庫の履歴」の「冷凍」の「取り消す」を押すと、作った袋も消えて常温に戻ります（取り出した袋があるときは、先にその「冷凍から取り出し」を取り消してください）
- 豆の詳細の「豆の情報」に、価格から計算した「1gあたり」と「1杯の原価」が出ます
- 「次の自分への一言」は、飲み切る前でもいつでも書けます。消すときは欄を空にして「一言を保存する」を押す
- 新しい袋で初めて淹れるときは、淹れる画面の上にも「前回の申し送り」が出ます。「前回のベストで淹れる」で前回の条件に切り替えられます

## 注意
- 「削除する」を押し、確認の箱で「削除する」を押すと、その豆と在庫の履歴が一覧から消えます（元に戻せません）
- 「飲み切りを取り消す」を押すと、前の状態（淹れていなければ「未開封」、淹れていれば「開封済み」）に戻ります
- 「1杯淹れた」は、アプリのタイマーを使わずに淹れた1杯用です（抽出の記録は残りません）。アプリで淹れて「保存する」を押した杯は、自動で残量が減るので押さないでください
