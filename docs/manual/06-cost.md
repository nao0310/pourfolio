# 6. コストと店の台帳

1杯いくらで飲んでいるか、毎月いくら使っているか、どの豆や店が値段のわりに満足できたかを見ます。

## コストを見る
1. トップ画面の下の「豆と在庫」を押す
2. 上の「コスト」を押す
3. 「この1か月」に、1杯の平均（直近30日）・淹れた杯・今月買った額・今月飲んだ額が出る
4. 「月の支出」に、今月から6か月分が並ぶ
   - 棒と金額は買った額（豆の価格＋送料。注文日の月）
   - 右の「飲 ○円」は、その月に淹れた杯の原価の合計
5. 「1杯の単価と満足度」で「銘柄」「焙煎度」「購入先」のどれかを押す
6. 表に、杯数・1杯の平均単価・平均★・★1つあたりの値段が並ぶ

## 店の台帳を見る
1. 「豆と在庫」の上の「店の台帳」を押す（コストの画面の下からも開けます）
2. 豆の「購入先」ごとに、買った袋の数と回数・使った金額・平均★・1杯の平均・よく買う豆が並ぶ
3. 気に入った店は、店名の右の「☆」を押す
4. 「○○をお気に入りにしました」と出て、☆が★に変わり、いちばん上に並べば完了（もう一度押すと外れます）

## コツ
- 1杯の原価＝粉量×豆の1gあたりの値段です。1gあたりは、価格÷届いた豆を量った重さで計算します。量っていない豆は、表記から見積もった重さで計算します
- 「★1つあたり」は1杯の平均単価÷平均★です。小さいほど、値段のわりに満足できた豆です
- 送料は1杯の原価に入れず、月の支出（買った額）に入れます
- 店名の全角・半角や空白の違いは、同じ店としてまとめます。店名を直したいときは、豆の編集で「購入先」を直す
- 選んだまとめ方（銘柄・焙煎度・購入先）は、次に開いたときも残ります

## 注意
- 価格を入れていない豆と、豆を選ばずに記録した杯は、金額に入りません（画面の下に件数が出ます）
- 冷凍の袋で淹れた杯も、同じ豆の値段で計算します
