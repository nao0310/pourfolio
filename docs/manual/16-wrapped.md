# 16. 年間まとめを見る（Coffee Wrapped）

1年の杯数・飲んだ産地・ベスト・好み・成長・提案の効果などを、カードを1枚ずつめくって振り返ります。1年は1月1日〜12月31日で、今年は今日までの分が出ます。

## まとめを開く
1. 画面の下のタブ「分析」を押す
2. 「見る」の並びの「年間まとめ」を押す（「その他」→「豆と分析のほかの画面」の「年間まとめ」からも開けます）
3. 茶色のカードに「2026年のコーヒー」と「1月1日〜11月18日（今日まで）」が出れば、正しく開けています
4. ほかの年を見たいときは、右上の「2026年」を押して年を選ぶ（記録のある年だけが並びます）
- 1月に「その他」や分析から開くと、前の年のまとめが開きます（年が明けてすぐは、振り返りたいのが前の年なので）。今の年は右上で選べます

## カードをめくる
1. カードを左にスワイプする（指で右から左へなぞる）と、次のカードが出る
2. カードの右側を押しても次へ進む。左側（3分の1）を押すと1枚戻る
3. カードの下の「次へ」「前へ」でも動ける。真ん中に「3 / 11」のように、いまの枚数が出る
4. 長いカードは、カードの中を上下にスクロールすると続きが見える

## カードの中身
- 「淹れた杯」：杯数、淹れた日数と豆の種類、続けて淹れた最長の日数、いちばん淹れた月、月ごとの棒
- 「飲んだ産地」：国の数と、地図の上の点（大きいほど多く飲んだ産地）。色の帯はコーヒーベルト。下に杯の多い順の5か所。地図に位置のない産地は、下に名前だけ出る
- 「ベスト」：いちばん好きだった豆（同じ銘柄で★を付けた杯が3杯以上のうち、平均★がいちばん高い豆）と、★の高い3杯。3杯の行を押すと、その杯の評価の画面が開く
- 「好みの傾向」：★がいちばん高かった焙煎度・精製・産地（3杯以上の区分だけ）
- 「成長の記録」：「年の後半は平均★が3.4から3.8に上がりました」のような一文（★のある杯が10杯から）、月ごとの平均★の折れ線、豆ごとのベストの9割に届くまでの平均杯数、年の前半と後半の再現性スコア
- 「提案の効果」：評価のあとの提案（「4. 提案を読む」）どおりに淹れた回の、提案の元になった杯の★と次の杯の★の平均（「★3.3 → ★3.6」）。上がった・同じ・下がった回数も出る
- 「天気と生活」：アイスとホットの杯数、天気の付いた杯数。★のある杯が30杯あると、時間帯・気温・季節で★の高めだったものが出る
- 「飲み頃」：飲み頃の山が出た豆の、山の真ん中の平均（「焙煎後 12日ごろ」）と、山がいちばん高かった豆
- 「お金とカフェイン」：買った豆の額（送料込み）、飲んだ豆の原価と1杯あたり、使った豆の重さ、カフェインの合計の目安
- 「2026年のまとめ」：数字を1枚にまとめたカード

記録が足りないカードは出ません（例：★を付けた杯がなければ「ベスト」は出ない）。

## まとめを画像にする
1. いちばん最後の「2026年のまとめ」のカードまでめくる
2. 「画像にする」を押す
3. カードの中に画像が出て、ボタンが「作り直す」に変わる
4. iPhoneでは「共有・保存」を押し、「画像を保存」を押すと写真に入る。PCでは「ダウンロード」を押す

## ホームの知らせ
- 12月1日〜1月31日に、その年（1月は前の年）に10杯以上淹れていると、ホームに「2026年のまとめができました」が出る
- 「年間まとめを見る」を押すと、その年のまとめが開く。右上の「×」で閉じると、その年の知らせはもう出ない

## コツ
- 分析の画面の「デモで見る」のあとに開くと、作り話の記録（80杯）でまとめの見え方を確かめられる
- 年末の前でも、今年の今日までの分を見られる

## 注意
- 画像には豆の名前が入る。人に送る前に中身を見てください
- 数字は記録が変わるとまとめ直します（保存はしません）
