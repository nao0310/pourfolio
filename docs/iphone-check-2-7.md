# iPhoneでの確認表（ステップ2-7）

いつもの1杯・カフェイン・QRを読む・共有・印刷・画像・引っ越しを、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。PCが必要な項目（G）は、できるときだけで構いません。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 2.7）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 2.7 になりました」と、変わったことが3つ出る。「閉じる」を押すと消える

## B. いつもの1杯とカフェイン
1. トップ画面に、茶色の大きなボタン「いつもの1杯（朝・昼・夜のどれか）で淹れる」が出て、その下にレシピと豆の名前、さらに下に「…によく淹れる組み合わせ（直近60日で○回）」と出る
2. ボタンを押すと、抽出の画面に変わり、そのレシピと豆が選ばれている。左上の「‹ 淹れる」で戻る
3. 少し下の「カフェイン」に「今日のカフェイン 約○mg／目安400mg」と棒が出る
4. 「今日の一杯」の画面で控える時刻を決めてあれば、「控える時刻 15:00 まで、あと○時間○分」（過ぎていれば「15:00を過ぎました…」）と出る

## C. QRを読む（いちばん大事）
1. トップ画面の「QRを読む（キャニスター・共有レシピ）」を押す
2. 「カメラで読む」を押すと、カメラの許可を聞かれる。「許可」を押す
3. 黒い枠にカメラの映像が出る（出なければ、その番号を教えてください）
4. PCの画面か紙で、次のDのQRを写すと、自動で次の画面に変わる
5. 「やめる」を押すとカメラが止まる

## D. キャニスターのQR
1. 「豆と在庫」→ ★を付けたことのある豆 →「キャニスター用QR」の「QRを表示する」を押すと、QRが出る
2. 別の端末（PCなど）で同じ豆の画面を開いてQRを出し、iPhoneの「QRを読む」で読む（PCがなければ「ラベルを印刷」で紙に印刷して読む）
3. 抽出の画面に変わり、上に「★がいちばん高かった杯：…」と出て、その豆が選ばれている
4. 標準のカメラアプリでは読まない（Safariで開いてしまい、記録が出ない）

## E. レシピの共有と取り込み
1. 「抽出」→ いつものレシピの「共有・印刷」を押すと、QRが出る
2. 「共有する（メッセージ・AirDropなど）」を押すと共有の画面が出る。「メモ」などに送ってみる
3. 「リンクをコピー」を押すと「リンクをコピーしました」と出る
4. 「その他」→「QRを読む」→「リンクを貼り付けて開く」の欄を長押しして「ペースト」→「開く」を押す
5. 「共有されたレシピ」の画面に、粉量・湯量・注湯の流れが出る。「レシピ帳に取り込む」を押すと「…をレシピ帳に入れました」と出る
6. 「抽出」のレシピ帳に同じ名前のレシピが増えている（確かめたら「編集」→「削除」で消してよい）

## F. 印刷・画像
1. Eの画面の「レシピカードを開く」を押す。白いカードの見本が出る。「A6」を押すと大きくなる
2. 「印刷する」を押すと印刷の画面が出る。見本を2本指で広げる → 共有ボタン →「"ファイル"に保存」でPDFにできる（保存しなくてよい。見本が1枚に収まっているかを見る）
3. 「分析」→「月次レポート」を押すと、今月の杯数・ベスト3・産地・好みの変化が出る。「印刷する」で同じように見本が出る
4. 「直近の抽出」から1杯を開き、いちばん下の「1枚の画像にする」→「画像を作る」を押すと、縦長の画像が出る
5. 「共有・保存」→「画像を保存」を押すと、写真アプリに入っている（確かめたら消してよい）

## G. 引っ越しとPCの自動保存（できるときだけ）
1. iPhoneで「その他」→「データ」→「書き出す」→「AirDrop」かメールでPCに送る
2. PCのChromeかEdgeでPourfolioを開き、「その他」→「データ」→「ファイルを選んで復元」で送ったファイルを選ぶと、「復元しました」と出て件数がそろう
3. PCの「データ」の画面に「自動ファイル保存（PC）」が出る（iPhoneには出ない）。「フォルダを選ぶ」で好きなフォルダを選ぶと「フォルダに保存しました…」と出て、そのフォルダに pourfolio-backup.json ができる

## H. 見た目
1. 文字が小さすぎる・ボタンが押しにくい・横にはみ出しているところがあれば、画面の名前と一緒に教えてください
