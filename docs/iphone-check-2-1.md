# iPhoneでの確認表（ステップ2-1）

通信なしで開けるか（オフライン動作）、ホーム画面に追加していないときの警告、新しい版への切り替えを、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 今の版にそろえる（このステップの初回だけ）
1. ホーム画面のPourfolioを開く
2. 画面のいちばん上に「新しい版があります」と出たら「更新する」を押す（出なければそのまま）
3. 「データ」を開き、「オフライン」の欄が「準備済み：通信がなくても開けます」になっている。「準備中」なら、一度アプリを閉じて開き直し、もう一度見る
4. 同じ欄に「アプリの版：（12文字の英数字）」が出ている

## B. 機内モードで使う（完了の確認）
1. コントロールセンターで機内モードをオンにする（Wi-Fiもオフになっていることを確かめる）
2. アプリの切り替え画面でPourfolioを上にはらって閉じ、ホーム画面のPourfolioから開き直す
3. トップ画面がいつもどおり出る（白い画面や「接続できません」にならない）
4. 「豆と在庫」「淹れる（レシピ）」「器具」「データ」を順に開ける。豆を押すと詳細が出る
5. 「今日の1杯」の「前回と同じで淹れる」→「スタート」→ 最後まで →「保存する」→ 味の評価を保存できる
6. トップ画面の「直近の抽出」のいちばん上に、今の1杯が出ている
7. 機内モードをオフにする

## C. ホーム画面に追加していないときの警告
1. Safariで公開URL（README.md に書いてあるアドレス）を開く
2. トップ画面のいちばん上に、赤い枠の「ホーム画面に追加して使ってください」と3つの手順が出ている
3. ホーム画面のPourfolioから開いたときは、この警告が出ない（いちばん下に「ホーム画面のアプリとして開いています」）

## D. 次の更新のとき（次のステップのマージ後に）
1. マージから数分たったら、ホーム画面のPourfolioを開き直す（閉じずに裏に回していたときは、10分以上たってから戻る）
2. 画面のいちばん上に「新しい版があります」が出る。「更新する」を押すと、画面が読み込み直される
3. 読み込み直したあと、画面が空になったり崩れたりしない（前のように古いファイルが混ざらない）
4. 抽出のタイマーの途中では「新しい版があります」が出ない
