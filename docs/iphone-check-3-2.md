# iPhoneでの確認表（ステップ3-2 次に買う豆、Ver 3.2）

3-2で作った「気になる豆」と「次に買う候補」を、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。前の表 `docs/iphone-check-3-1-1.md` がまだなら、先にそちらを済ませてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。珈琲問屋の気になる豆の商品ページを1つ、Safariで開いておく。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 3.2）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 3.2 になりました」と、変わったことが3つ出る
3. 前からの豆・抽出・実験の記録が、そのまま残っている

## B. 気になる豆を足す
1. 「豆と在庫」の上の小さなリンクの並びに「気になる豆」がある。押すと「気になる豆」の画面が開く
2. Safariの商品ページで文章を全部選んでコピーし、「珈琲問屋の商品ページから入れる」の枠に貼って「読み取る」を押すと、銘柄・生産国・精製・焙煎度・価格が下の欄に入る
3. 「価格」の欄の「○gで ○円」が1行に収まり、数字を入れやすい
4. 「足す」を押すと、画面の上に「『○○』を足しました」と出て、「まだ買っていない豆」に予想★とおすすめの焙煎度が出る
5. 「直す」で直して「保存する」、「消す」でアプリの中の確認の箱が出て消せる
6. 「買った」「直す」「消す」のボタンが、片手の親指で押し分けられる

## C. 次に買う候補
1. 「買い物リスト」の「次に買う候補」に、足した気になる豆と、これまでに買った豆が並ぶ
2. 銘柄の横に「定番」「開拓」の札が出て、ライト・ダークどちらでも読める
3. 候補ごとに「予想★」、理由（「この豆の★平均…」「まだ飲んだことのない産地（…）」など）、「焙煎度は…（…）」が出て、文字が切れたり横にはみ出したりしない
4. 2つに印を付けると、「注文メモ」に「・銘柄 ○○ロースト 生豆時○g ○円」の行が2つと、最後に「量は飲むペースの28日分を2種で分けた目安」が出る
5. 「メモをコピー」を押し、メモアプリに貼ると、同じ文が貼れる

## D. 買ったとき
1. 「気になる豆」の画面で「買った」を押すと豆の登録の画面が開き、上に「気になる豆『○○』の内容を入れました」と出る
2. 状態が「入荷待ち」、焙煎度がおすすめのものになっている
3. 表記重量を200に直すと、価格が200gの値段に変わる（商品ページから足した豆のとき）
4. 「登録する」を押したあと「気になる豆」に戻ると、その豆が「購入済み」に移っている
5. 買い物リストでは、その豆が「気になる豆」ではなく「1袋買った」として出る（二重に出ない）

## E. 書き出しと復元
1. 「その他」→「データ」で書き出したファイルに気になる豆が入り、復元しても消えない（いつもの書き出しのついでで大丈夫です）
