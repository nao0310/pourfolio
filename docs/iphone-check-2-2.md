# iPhoneでの確認表（ステップ2-2）

Verの番号、注文メールと商品ページの読み取り、入荷待ちと到着、買い物リストを、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版とVer
1. 画面のいちばん上に「新しい版があります」が出たら「更新する」を押す（今回は、前の版に番号の仕組みがないため「（Ver 2.2）」は付きません）
2. トップ画面のいちばん上に「Ver 2.2 になりました」と、変わったことが3つ出る
3. 「閉じる」を押すと消える。アプリを開き直しても、もう出ない
4. トップ画面のいちばん下に「Ver 2.2」が出ている
5. 「データ」の「アプリの版とオフライン」に「Ver 2.2（英数字8文字）」が出て、「更新履歴」を押すと Ver 2.2〜0.2 の変更が出る

## B. 注文メールから登録（完了の確認）
1. メールアプリで、珈琲問屋の「ご注文ありがとうございます」のメールを開き、本文を長押し →「すべてを選択」→「コピー」
2. Pourfolioの「豆と在庫」→ 上の「注文メールから登録」→ 枠に貼り付けて「読み取る」
3. 注文番号・注文日・送料と、注文した豆（銘柄・焙煎度・グラム数・数量・価格）がメールと合っている
4. 「入荷待ちとして登録」を押すと、「豆と在庫」に「入荷待ち」の札が付いた豆が並ぶ
5. 同じメールでもう一度「読み取る」を押すと「この注文は登録済みです」と出る（登録はしない）

## C. 届いたとき
1. 「入荷待ち」の豆を押し、「量った重さ」に重さを入れて「届いた」を押す（試すだけなら、どれか1袋で）
2. 「飲み頃」と「残り」が出て、豆の一覧の札が消える
3. 「淹れる」の豆の選択で、届いた豆は選べ、まだ入荷待ちの豆は出ない

## D. 商品ページから入れる
1. Safariで珈琲問屋の豆の商品ページを開き、文章を長押し →「すべてを選択」→「コピー」
2. 「豆と在庫」→「＋ 豆を登録」→「珈琲問屋の商品ページから入れる」→ 貼り付けて「読み取って入れる」
3. 銘柄・産地・精製・価格・店の風味説明が入っている
4. 「表記重量」を200にすると、価格が200gの値段に変わる
5. 登録はしなくてよい（左上の「豆と在庫」で戻る）。試しに登録した豆は、豆の画面の「削除」で消せる

## E. 買い物リスト
1. 「豆と在庫」→「買い物リスト」を押す
2. いちばん上に「次の注文は○/○ごろ」などと、手元の豆・入荷待ち・お届け7日が出る（2週間で2杯未満のときは「2杯以上淹れると…」）
3. 候補に印を付けると注文メモができ、「メモをコピー」でメモアプリに貼れる

## F. 機内モード
1. 機内モードにして、アプリを閉じて開き直し、「注文メールから登録」と「買い物リスト」が開ける
2. 機内モードを戻す
