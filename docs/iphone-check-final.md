# iPhoneでの確認表（総仕上げ、Ver 3.6.1）

総仕上げ（3-6 のあと）で直したところを、iPhoneで確かめるための表です。この作業環境には Safari のエンジン（WebKit）がないため、ここに書いたことは **Chrome（Chromium）でしか確かめていません**。Safari でしか起きないことがあるかもしれないので、1つずつ試してください。終わったら、うまくいかなかった番号を教えてください（全部できたら「全部できました」）。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面に「新しい版（Ver 3.6.1）があります」が出たら「更新する」を押す
2. ホームの「今日の1杯」の下に「Ver 3.6.1 になりました」と、変わったことが3つ出る。読んだら「閉じる」を押す
3. 前からの豆・抽出・評価の記録が、そのまま残っている

## B. 字形（日本語の形になっているか）
1. 「その他」を押し、題や一覧の「直」「骨」「角」「写」「今」の字を、iPhoneの「メモ」など、ほかの日本語のアプリで同じ字を書いたものと見比べる。同じ形になっている
2. 豆の画面で、豆の名前の入力欄・選ぶ欄（焙煎度など）の文字も同じ形になっている
3. 抽出レポートの「1枚の画像にする」と、年間まとめの最後の「画像にする」で作った画像の文字も同じ形になっている
4. 気になる字があれば、その画面の名前と字を教えてください（iPhone の言語の設定が「日本語」以外のときに起きやすい）

## C. 「戻る」と、開いたまま日をまたぐ
1. 豆の一覧 → ある豆を開く → 下のほうの「削除する」→ 確認の箱で「削除する」→ 一覧に戻る。そこで画面の左の端から右へスワイプして「戻る」をする。前の豆の一覧が出るが、一瞬読み込み直して、削除した豆はその一覧に出ない
2. 夜（23時ごろ）にホームを開いたまま、ホームボタン（または下からスワイプ）でアプリを裏に回す。次の朝6時以降にアプリに戻ると、「今日のカフェイン」が0mgから（昨日の量のまま出ない）
3. 淹れている途中（タイマー中）にアプリを裏に回して戻ると、タイマーは続きから進む（読み直しで止まらない）

## D. 2度押し・取り消し
1. 豆の画面の「飲み切りにする」をすばやく2回押す。「飲み切りにしました」になり、2回目で取り消しにならない
2. 豆の画面の「在庫の履歴」で、淹れた杯（抽出の記録とつながった「抽出」の行）には「取り消す」が出ない
3. 残りが10gの豆で「1杯淹れた」に15gを入れて押すと、「常温の残り（10g）より多く使います」の確認の箱が出る
4. 豆の削除など確認の箱が出るボタンをすばやく2回押すと、箱が開いたまま残る（すぐ閉じない）
5. 「その他」→「データ」の「書き出す」をすばやく2回押しても、共有の画面は1回だけ出る。2回目で「書き出せませんでした」が出ない

## E. 淹れる画面
1. タイマーの途中で、上の「ベストは …を 0:11 に注ぎ終え」の行が1行に収まっていて、下の「読み上げ オン」と重ならない
2. 画面が消えないことの注意（「設定の「自動ロック」を長くすると画面が消えません」）が出るiPhoneでは、それも1行に収まる
3. タイマーを始めたまま閉じて、1時間以上たってから開くと、タイマーではなく「実績の確認」が開き、「○時間前に始めた1杯です」と出る。ホームの「淹れている途中の1杯があります」には、始めた時刻が出る

## F. ホームと言葉
1. ホームを開くと、いちばん上のほうに「いつもの1杯で淹れる」が見える（お知らせのカードは「今日の1杯」の下）
2. 戻るリンクやボタンが「トップ」ではなく「ホーム」になっている（例：「豆と在庫」の左上「‹ ホーム」）
3. 「データ」の画面のいちばん下の見出しとボタンが「すべて削除する」になっている（押さないでください）

## G. 保存できない開き方・通信なし（Safari だけで起きやすいこと）
1. Safari のプライベートブラウズで、アプリのURL（README.md にあるもの）を開く。画面のいちばん上に赤い枠で「この開き方では記録を保存できません」が出る（出なくても、記録が普通にできれば問題ありません。その場合は「Gの1は記録できた」と教えてください）。確かめたらプライベートのタブは閉じる
2. 機内モードにして、ホーム画面のPourfolioを開く。下のタブの5つの画面がどれも開く
3. 機内モードのまま「その他」→「天気の地点」を開くと、「通信できません。通信が戻ると天気を入れます」と出る
4. 機内モードを外してホームを開き直すと、機内モードのあいだに淹れた杯にも天気が付く
5. 天気が受け取れなかったとき、かっこの中に英語（「Load failed」など）が出るのは決まりどおりです（原因を確かめるため、D-166）

## H. 1月と月初め（その日になったら）
1. 1月に「分析」→「年間まとめ」を開くと、前の年のまとめが開く
2. 月の1〜3日に、その月にまだ淹れていない状態で「月次レポート」を開くと、先月のレポートが開く
