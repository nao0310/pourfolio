# iPhoneでの確認表（ステップ3-1 の手直し、Ver 3.1.1）

前の確認で出た「ボタンの文字の位置」「言葉の途中の改行」「長い文」を直しました。同じ所をもう一度見てください。終わったら、気になる所が残っていれば画面の名前と文の一部を教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直し、「新しい版（Ver 3.1.1）があります」が出たら「更新する」を押す。

## A. ボタン
1. 「実験」の画面の「この飲み比べを始める」「最適化を始める」、飲み比べの画面の「淹れる」で、文字がボタンの上下の真ん中にある
2. ほかの画面（ホーム・豆の画面・淹れる画面）のボタンも、文字がずれたり、ボタンが横に伸びたりしていない

## B. 改行
1. 「実験」の画面の「次に試す実験」で、「挽き目 24 → 22」が1行にまとまり、その下に「2目盛り細かく」と理由が短く出る
2. 飲み比べの画面の題名（「…挽き目の飲み比べ」）や結果の文が、言葉の途中（「飲み比 / べ」など）で折れていない
3. 最適化の画面の「次の1杯」「今のいちばん」の文が、「挽き目 20・比率 1:17.5」のまとまりで折れている

## C. 文の長さ
1. トライアングルの「2. 当てる」が、番号付きの3行の手順になっている
2. 答え合わせのあとの成績が「1回中1回当たり。まだ偶然と区別できません…」のように短い

## D. 下のタブ（いちばん大事）
1. ホーム画面に追加したアプリで、下のタブを使って10回ほど画面を移る（ホーム → 豆と在庫 → 豆を1つ開く → 戻る → 分析 → その他 → 実験 …）
2. どの画面でも、下までスクロールしたとき、5つのタブが画面のいちばん下に付いたまま動かない
3. 1日ほどふだんどおり使っても、タブが上へ動くことがない
4. 画面を移るときの「ふわっ」とした動きはなくなるが、タブが一瞬消えたり、白く光ったりしない
