# iPhoneでの確認表（ステップ2-5）

下のタブ・分析の画面・TDS・水・目盛り表・ゴーストを、iPhoneで確かめるための表です。終わったら、うまくいかなかった番号だけ教えてください。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面のいちばん上に「新しい版（Ver 2.5）があります」が出たら「更新する」を押す
2. トップ画面のいちばん上に「Ver 2.5 になりました」と、変わったことが3つ出る。「閉じる」を押すと消える

## B. 下のタブ
1. トップ画面のいちばん下に「ホーム」「抽出」「豆と在庫」「分析」「その他」のタブが並び、「ホーム」に色が付いている
2. それぞれ押すと画面が変わり、押したタブに色が付く。親指で押しやすい
3. 「豆と在庫」では、「＋ 豆を登録」のボタンがタブのすぐ上に出て、重なっていない
4. iPhoneの下の横線（ホームバー）とタブが重なっていない
5. 「抽出」からレシピの「淹れる」を押すと、タブが消える（淹れる画面・評価の画面・登録の画面には出ない）

## C. 分析をデモで見る（完了の確認）
1. タブ「分析」を押し、いちばん下の「デモで見る」を押す
2. 上に点線の枠「デモデータを表示しています」が出る。「見る」の6つが全部「見られます」になっている
3. 「ダイヤルインの道のり」：豆を選び替えると、★の折れ線と杯ごとの「変えた：…」が変わる
4. 「抽出チャート」：点・点線の四角・斜めの線・塗った四角（自分の好きゾーン）が出る。点を長押しすると日付と★が出る
5. 「条件と評価」：4つのグラフと「飲み頃カーブ」が出る
6. 「嗜好プロファイル」：産地などの横棒と、「産地×焙煎度」の表が出る。表は横にはみ出さない（はみ出すときは表の中だけ横に動く）
7. 「カレンダーとカフェイン」：カレンダーと棒グラフが出る。「‹ 前」で前の月に移る
8. 「自分のデータに戻る」を押すと、点線の枠が消え、自分の記録の件数に戻る
9. 文字やグラフが小さすぎて読めないところがあれば、その画面の名前を教えてください

## D. TDS（屈折計を持っているときだけ）
1. 1杯淹れて「実績の確認」で「TDS（屈折計）」に 1.35 を入れて保存する
2. 評価の画面のいちばん下の「TDS（屈折計）」に 1.35 と「抽出収率 ○%」が出る
3. 値を 1.40 に直して「保存」を押すと「TDSを保存しました」と出て、収率が変わる
4. タブ「分析」→「抽出チャート」に点が1つ出る

## E. 水と目盛り表
1. タブ「その他」→「器具と水」→「＋ 器具・水を登録」→「水」を押し、成分を入れると「SCAの基準との差」が変わる。保存すると一覧の「水」に出る
2. 次に淹れたとき、「実績の確認」の「水」に登録した水が選ばれている
3. グラインダーを2台登録して目盛り表を2行ずつ入れると、「器具と水」の下に「目盛りの換算」が出て、目盛りを入れると別のミルの目盛りが出る（グラインダーが1台なら、この項目は飛ばしてよい）

## F. タイマーのゴーストと横向き
1. ★を付けたことのあるレシピで「スタート」を押す
2. 「次の注湯まで」の下に「ベスト（★○・○/○）は 蒸らしを 0:○○ に注ぎ終え」と出る
3. 注湯完了を押すと「ベスト比 +○秒（蒸らし）」に変わる
4. iPhoneを横にすると、左に数字、右に「注湯完了」の大きなボタンが出て、文字が切れない（画面の縦向きロックを外して確かめる）
5. 縦に戻すと元の並びに戻る
