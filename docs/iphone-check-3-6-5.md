# iPhoneでの確認表（ホーム画面のアプリでキーボードの高さを正しく数える直し、Ver 3.6.5）

前回送ってもらった「キーボードの点検」の数字から、原因が分かりました（D-187）。ホーム画面のアプリでは、キーボードが出ると、アプリの画面の高さが 812 から 674 に縮み、画面全体も 138 ずれます。3.6.4 まではキーボードの高さを 128 と小さく数えていました（本当は 404 くらい）。そのため、隠れている欄を「見えている」と思って動かしていませんでした。3.6.5 では、キーボードが出る前の画面の高さから数えます。138 のずれは、どちらの意味でも欄が見える所に置くようにしました。この作業環境には Safari がないので、ここでは前回の数字を Chrome でまねて確かめただけです。

準備：マージから数分たったら、ホーム画面のPourfolioを開き直す。

## A. 新しい版
1. 画面に「新しい版（Ver 3.6.5）があります」が出たら「更新する」を押す（出なければ、アプリを閉じて開き直す）
2. 「その他」→「データ（書き出し・保存）」の「アプリの版とオフライン」が「Ver 3.6.5」になっている

## B. レシピの編集（いちばん大事）
1. 「その他」→「レシピ帳」→ レシピを1つ開いて「編集する」を押す
2. 画面を少し上へなぞって、「目標の抽出時間（落ち切りまで）」の欄が画面の下の端に来るようにする
3. その欄を押す。欄が、欄の名前ごとキーボードの上の見える所に出る（キーボードの上の「^ v ✓」の帯にも隠れない）
4. 数字を1つ入れる。入れた数字が見える
5. キーボードの上の「v」を押してメモへ移る。メモもキーボードの上に見える
6. 「✓」を押して閉じる。下の「保存する」が画面のいちばん下にあり、下にすき間がない
7. 保存しないで戻る

## C. キーボードの点検（うまくいかなかったときだけ）
1. 「その他」→「データ（書き出し・保存）」の「キーボードの点検」で、画面を少し上へなぞって「ためしに押す欄」を画面の下のほうに置いてから押す
2. キーボードが出たまま2秒待ち、画面写真を撮る
3. 「✓」を押して閉じ、もう一度画面写真を撮る（数字の行がすべて見えるように）
4. 2枚とも送ってください

## D. ほかの画面（下のほうの欄を押して、欄が見えるか）
1. 「豆と在庫」→「豆を登録する」→ いちばん下の「メモ」
2. 豆を1つ開く →「次の自分への一言」、「おすそ分け・廃棄」の中の欄
3. 1杯淹れて「実績の確認」→ 下のほうの「TDS」「メモ」（いつもどおり淹れるときで大丈夫です）
4. 評価の画面 →「メモ」
5. 「その他」→「AIに相談」→「AIの答え」

## E. 副作用がないか
1. 画面の上のほうに見えている欄（豆の登録の「名前」など）を押す。欄は見えたままで、大きく跳ねない
2. 選ぶ欄（レシピの編集の「グラインダー」「注ぎ方」、豆の登録の「品種」など）と日付の欄（豆の登録の「焙煎日」）を押す。選べる
3. 文字を入れて閉じたあと、ホーム・豆と在庫・分析・その他で、下のタブが画面のいちばん下にあり、上に浮いていない
4. Safari で開いたときも、B の3と同じように欄が見える

終わったら、うまくいかなかった番号を教えてください（全部できたら「全部できました」）。B がうまくいかなかったときは、C の画面写真もお願いします。
