# Pourfolio

個人用のコーヒー（ハンドドリップ）記録・分析・提案アプリ。費用ゼロで、記録データは使っている端末の中にだけ保存されます。

- 公開URL：https://nao0310.github.io/pourfolio/
- 設計：`docs/spec.md`
- 進捗：`docs/PROGRESS.md` ／ 決定事項：`docs/DECISIONS.md` ／ ステップ一覧：`docs/ROADMAP.md`
- 使い方：`docs/manual/`

## 使い方

1. iPhone の Safari で https://nao0310.github.io/pourfolio/ を開く
2. 画面の下の「共有」ボタン（四角から上向きの矢印）→「ホーム画面に追加」→ 右上の「追加」を押す
3. これからは、ホーム画面の **Pourfolio** から開く（Safari で開いたままだと、7日ほど開かなかったときに記録が消えることがあります）
4. 下のタブ「豆と在庫」→「＋ 豆を登録する」で、買った豆を登録する
5. 下のタブ「淹れる」でレシピを選び、タイマーに合わせて淹れて「保存する」を押す
6. 続けて出る「味の評価」で★などを付けて保存すると、次の1杯の直し方が出る
7. ときどき「その他」→「データ（書き出し・保存）」→「書き出す」で、記録をファイルに書き出しておく（機種変更や、記録が消えたときに「復元」で戻せます）

- PC の Chrome・Edge でも使えます。PC ではフォルダに自動で保存する機能も使えます
- 通信がなくても使えます（天気の受け取りだけは通信が要ります）
- 画面ごとの詳しい手順は [使い方手順書（docs/manual/）](docs/manual/README.md) にあります
